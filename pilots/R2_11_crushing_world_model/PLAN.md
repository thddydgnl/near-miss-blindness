## 1. 원문 주장, 질문, 가설 (IDEAS_ROUND2.md에서 복사)

**원문 주장.** InceptionV1 3b를 480 → 10, ConvNeXt 마지막 층을 1024 → 13으로 좁혀 재학습해도 뉴런이 무관한 것을 겹쳐 담지 않았다(packing 없음). 대신 더 굵은 범주로 묶였다(coarsening). 좁힌 층의 SAE도 원래 detector를 복원하지 못했다. residual을 4·8배 좁혀도 지도는 "조금 더 지저분할 뿐"이었다.

**피지컬 AI 질문.** on-robot 배치를 위해 월드모델을 작게 만들면 어떤 물리 구분이 먼저 사라지는가? 원문이 맞다면 작은 월드모델은 비슷한 물리 상태를 묶는 방향으로 거칠어지고, 무관한 변수를 섞지 않는다. 그렇다면 미세 구분(접촉 직전 vs 접촉, 작은 위치·회전 차이)이 먼저 사라지고, 계획은 그 미세 구분이 필요한 과제부터 실패한다. packing이 일어나면 무관한 변수(에이전트 위치와 상자 회전 등)가 섞여 이상한 오류가 난다.

- H1 (coarsening): 예측기의 은닉(MLP 또는 residual) 폭을 줄이면 예측 특징에서 읽히는 물리 변수의 해상도가 떨어진다. 하지만 변수 간 혼동(한 변수의 오차가 무관한 변수 값에 따라 달라지는 정도)은 늘지 않는다.
- H2 (계층): 사라지는 순서는 물리 구분의 "넓이"(데이터에서 차지하는 분산 몫)를 따른다. 좁은 구분이 먼저 사라진다.
- H3 (유닛 수준): 좁힌 모델의 뉴런은 넓은 모델의 여러 뉴런을 합친 거친 버전이다. 각 뉴런의 GT 변수 집합이 의미적으로 국소적이다(SLI와 비슷하게 잰다).
- H4 (계획): 폭을 줄일 때 CEM 성공률은 미세 구분이 필요한 목표(정밀 위치)에서 먼저 떨어진다.

## 2. R2-2 대비 바뀐 것과 이유 (본 실행 전 결정)

1. **상자 회전 추가.** GT 변수 목록에 상자 회전이 있는데 R2-2 환경의 상자는 회전하지 않는다. 그래서 `code/env.py`에 회전을 넣었다.
   - 원판-회전 사각형 접촉, 접촉점에 비탄성 충격량(선·각운동량), 관성 IB = MB(2HB)²/6, 각속도 마찰 15%/substep
   - 벽 처리: 회전한 사각형의 축 정렬 범위로 위치를 자르고, 벽에 닿으면 각속도를 절반으로 줄인다.
   - 나머지 상수·정책·substep·렌더 색은 R2-2와 같다. 초기 각도는 [0°, 90°) 균등
   - 기록 행동 재실행 오차 0.0(결정론)
2. **폭 정의(MLP 비율 1).** 두 crush 조건의 폭 256 모델을 같은 모델로 둬서 공통 넓은 기준으로 쓴다. 분석할 뉴런층(MLP hidden)의 뉴런 수가 두 조건 모두 정확히 d가 되게 했다.
   - MLP-hidden-only crush: d_model = 256 고정, 모든 블록의 MLP hidden = d
   - residual-width crush: d_model = d, MLP hidden = d (residual 우회로 없음)
   - d = 256이면 두 조건 모두 (256, 256)이다. 공유 기준 `w256`
   - 헤드 수 max(1, d_model/32). 나머지 구조(6층, zero-init AdaLN 행동 경로, zero-init head, ẑ = z_t + head)는 R2-2와 같다.
3. **학습 설정.** 시간 때문에 batch 256, 6,000 step(1.54M 표본, 학습 세트 약 16 epoch)으로 정했다. R2-2는 batch 128에 최대 12k step을 썼다. timing 측정: 두 프로세스 병렬 360 ms/it.
   - lr 6e-4, warmup 300 후 cosine으로 0.1배까지 감쇠
   - AdamW(0.9, 0.98), wd 0.05, clip 1.0, bf16
   - 모든 모델이 같은 step 수와 같은 minibatch 순서(시드별)로 학습한다.
4. **해상도 지표를 혁신 R²로.** 위치의 원시 R²는 현재 프레임을 복사하기만 해도 0.98 근처라 0.1 하락이 원리상 불가능하다. 그래서 복사 기준선 대비 skill(4.1절)을 주 지표로 쓰고 원시 R²는 함께 보고한다. "probe R² 0.1 하락"은 이 혁신 R²에 적용한다.

## 4. 측정 (정확한 정의, code/analyze.py)

### 4.0 GT 변수 (프레임 t+1, 6개)

| 기호 | 변수 | 정의 |
|---|---|---|
| A | 에이전트 위치 | pa(t+1) (x, y) px |
| B | 상자 위치 | pb(t+1) (x, y) px |
| R | 상자 회전 | (cos 4θ, sin 4θ) at t+1 (정사각형 90° 대칭) |
| C | 접촉 | 프레임 접촉 플래그: 에이전트 원판과 상자 표면 간격 ≤ 0.5 px |
| W | 벽 근접 | 상자(회전 범위)와 가장 가까운 벽 사이 간격, [0, 20] px로 자름 |
| S | 상자 속도 | ‖pb(t+1) − pb(t)‖ px/step |

**의미 거리 행렬 D** (본 실행 전 고정, 순서 A B R C W S)

| | A | B | R | C | W | S |
|---|---|---|---|---|---|---|
| A | 0 | .5 | 1 | .5 | 1 | 1 |
| B | .5 | 0 | 0 | .5 | 0 | .5 |
| R | 1 | 0 | 0 | 1 | .5 | .5 |
| C | .5 | .5 | 1 | 0 | .5 | .5 |
| W | 1 | 0 | .5 | .5 | 0 | .5 |
| S | 1 | .5 | .5 | .5 | .5 | 0 |

- 0 = 같은 대상의 같은 종류(상자 자세: 위치·회전·벽 간격), 0.5 = 물리적으로 연결(같은 대상의 다른 종류, 상호작용, 다른 대상의 같은 종류), 1 = 무관
- 무관 쌍(D = 1): A–R, A–W, A–S, R–C. 원문 예시인 "에이전트 위치와 상자 회전"이 여기에 들어간다.
- "에이전트 위치 + 상자 위치"를 한 뉴런이 담으면 "여기에 물체가 있다"는 거친 범주라서 coarsening(0.5)으로 본다.
- 15쌍 평균 D̄ = 0.567

### 4.1 해상도 (예측 특징 probe)

- 각 모델로 ana 세트 전 표본의 예측 ẑ_{t+1}을 만든다.
- probe: 선형 kernel ridge(쌍대형). 입력 = [ẑ_{t+1}, z_t](각 24,576차원, 학습 평균 중심화)
  - 대조 probe 1, 복사(입력 복사 대조): 입력 = z_t만
  - 대조 probe 2, oracle: 입력 = [z_{t+1}, z_t]
- λ는 probe 학습 에피소드 안의 검증 분할(0–179 적합, 180–239 검증)로 목표 열마다 고르고, 학습 에피소드 전체로 다시 적합한다. 시험 에피소드에서 평가한다.
- **혁신 R²(주 지표)**: R²_Δ,i = 1 − MSE_i(model) / MSE_i(copy). 다차원 변수는 차원을 합쳐 계산한다.
- 원시 R²(1 − MSE/Var)와 oracle R²_Δ도 보고한다.
- **해석 가능 변수**: oracle R²_Δ ≥ 0.2인 변수만 S1·S3 판정에 쓴다(인코더+probe가 그 변수의 변화를 읽지 못하면 월드모델 해상도를 말할 수 없다).

### 4.2 혼동 지표 (S1)

- 변수 i의 probe 시험 오차 e_i = v̂_i − v_i를, 그 변수와 무관한 변수들 U(i)의 비선형 기저로 회귀한다.
  - U(A) = {R, W, S}, U(R) = {A, C}, U(C) = {R}, U(W) = {A}, U(S) = {A}. B는 무관 변수가 없어 제외
- **부분 R²** = R²(e_i ~ [자기 기저 O_i, U 기저]) − R²(e_i ~ O_i). 자기 기저를 넣는 이유는 probe의 평균 회귀 편향이 상관된 다른 변수로 새는 것을 막기 위해서다.
  - 2-fold 교차 적합(시험 에피소드 홀짝), ridge(λ = 1e-3·n)
- 기저
  - A, B: 7×7 RBF 격자 + 선형
  - R: cos/sin 4θ, 8θ
  - C: 플래그 + 간격 RBF 4개
  - W: 간격 RBF 5개 + 접촉 플래그
  - S: 속도 RBF 5개 + 선형
- 모델 혼동 지수 CI = 5개 변수 부분 R²의 평균. 같은 계산을 관련 변수(D ≤ 0.5) 기저로 한 CI_rel과 oracle CI도 보고한다.
- 유의성: 시험 에피소드 bootstrap 200회. 모든 모델이 같은 재표본을 써서 짝 비교가 된다. ΔCI = CI(d=8) − CI(256)의 시드 평균과 95% 구간을 구한다.
  - **"유의하게 늘었다"** = 95% 구간 하한 > 0 **그리고** ΔCI ≥ 0.02

### 4.3 뉴런 국소성 (S2)

- 유닛: 6개 블록 MLP hidden의 GELU 출력 채널 j(블록당 d개). 현재 프레임 토큰 64개 위치의 활성을 쓴다.
- 표본: ana에서 학습 3,200개(에피소드 0–239), 시험 1,200개(240–399)
- 부호화 모형: 토큰마다 따로 ridge 회귀한다. 채널 j의 토큰 p 활성을 GT 특징 가족 6개로 회귀하고, 가족은 변수 A B R C W S에 대응한다.
  - A: pa(t), pa(t+1)의 7×7 RBF와 변위
  - B: pb(t), pb(t+1)의 7×7 RBF
  - R: cos/sin 4θ, 8θ와 (cos, sin 4θ) × 상자 4×4 RBF
  - C: 접촉 플래그, 간격 RBF, 접촉 × 에이전트 4×4 RBF
  - W: 벽 간격 RBF, 벽 접촉 플래그, 벽 접촉 × 상자 4×4 RBF
  - S: 상자 변위, 속도 RBF, 속도 × 상자 4×4 RBF, |Δθ|
  - λ는 블록마다 검증 분할로 고른다.
- 고유 분산 E[j, i] = (SSE_{−i} − SSE_full) / SST. 시험 표본에서 64개 토큰을 합쳐 계산한다. R²_full(j) ≥ 0.1인 채널만 포함한다.
- **가중 국소성 L_w(주 지표)**
  - p = max(E[j,:] − 0.005, 0)를 정규화한 가족 분포
  - spread = Σ_{i,k} p_i p_k D(i,k)
  - L_w(j) = 1 − spread / 0.472(균등 분포의 spread)
  - 단일 가족 유닛은 1이다. 모델 값 = 포함 유닛 평균(6블록 합침)
- 보조 지표
  - 임계 SLI: GT 집합 R(j) = {i : E[j,i] ≥ max(0.01, 0.3·max E[j,:])}. 다중 가족 유닛에서 1 − mean D / D̄
  - packing 비율: R(j)에 무관 쌍이 있는 유닛의 비율
  - 다중 가족 비율
- null
  - (1) 무작위 회전: 블록마다 직교 회전 10개를 채널에 적용하고 같은 계산을 반복한다.
  - (2) 학습 전 모델: 같은 시드·구조의 초기값

### 4.4 합쳐진 뉴런 점검 (H3, 판정 외 보고)

- 좁은 모델(d = 64, 16, 8) 블록 b의 각 뉴런을, 같은 시드 w256 블록 b의 뉴런 256개로 회귀한다(표본×토큰 합침, 시험 분할에서 평가).
  - R²_1: 가장 좋은 단일 뉴런
  - R²_5: greedy OMP 5개
  - R²_all: ridge 전체
- top-5 넓은 뉴런의 GT 프로필 간 기대 의미 거리를 무작위 5개 집합과 비교한다.
- null: 넓은 뉴런 회전(3개), 학습 전 좁은 모델. 참고값: w256 시드 1 → 시드 0

### 4.5 분산 몫 (S3)

- 실제 특징 혁신 Δz = z_{t+1} − z_t(ana 전체)를 가족 i의 특징만으로 ridge 회귀한다. 시험 R²(전 차원 합침)가 share_i다.
- 해상도 손실(상대) = 1 − R²_Δ,i(d=8) / R²_Δ,i(256), 시드 평균

### 4.6 CEM (S4)

- 과제: id 에피소드에서 64개, 고정 seed
  - 밀기 32개: 지평 5 step 동안 상자 이동 ≥ 3 px 또는 회전 ≥ 5°
  - 자유 32개: 상자 이동 < 0.5 px, 회전 < 0.5°
  - 시작 = 프레임 t(이력 t−2..t), 목표 = 같은 에피소드의 프레임 t+5(기록 행동으로 도달 가능)
- CEM: H=5, 개체 256, elite 32, 반복 5, 초기 sd 0.7, 비용 = 특징 MSE. 시뮬레이터에서 open-loop 실행(R2-2와 같음)
- 허용 오차(본 실행 전 고정)
  - **정밀 목표 성공**: 에이전트 ≤ 2 px **그리고** 상자 ≤ 2 px **그리고** |Δθ| ≤ 5°(90° 대칭)
  - **거친 목표 성공**: 에이전트 ≤ 8 px **그리고** 상자 ≤ 8 px
- 기준선: 기록 행동(100%여야 함), 0 행동, 무작위 행동
- **변별력 조건**: w256의 거친 성공률이 max(0 행동, 무작위)의 2배 이상이고 30%p 이상 높아야 한다. 아니면 S4는 판정 불가다.

## 6. 판정 기준

### 6.1 원문 (IDEAS_ROUND2.md R2-11)

- S1 (coarsening, not packing): 가장 좁은 폭에서 GT 해상도가 떨어진다(probe R²가 0.1 이상 하락). 그러나 혼동 지표는 넓은 모델 대비 유의하게 늘지 않는다(조건 2개 중 2개).
- S2 (국소성): 좁은 모델 뉴런의 GT 집합 국소성이 회전 null보다 높다. 폭을 줄여도 국소성이 떨어지지 않거나, 떨어지더라도 해상도 손실보다 작다.
- S3 (계층, 권장): 변수별 해상도 손실 순서와 그 변수의 분산 몫 순서의 Spearman이 0.6 이상이다.
- S4 (계획, 권장): 폭 감소에 따른 CEM 성공률 하락이 정밀 목표에서 거친 목표보다 2배 이상 크다.
- 판정
  - S1과 S2를 만족하면 있음: 원문 crushing 주장이 월드모델에서 성립하고, 작은 월드모델의 실패 모드가 예측 가능하다.
  - 그 외는 조건부 또는 없음

### 6.2 채운 세부 (본 실행 전 결정)

- 공통
  - "조건 2개" = MLP-hidden crush와 residual-width crush
  - "가장 좁은 폭" = d = 8, "넓은 모델" = w256(같은 시드)
  - 값은 시드 2개 평균이다.
  - S2~S4도 두 조건 모두에서 성립해야 통과로 하고, 한 조건만이면 "부분"으로 적는다.
- **S1** (조건마다)
  - (a) 해석 가능 변수들의 R²_Δ 하락(w256 − d8)의 평균 ≥ 0.1
  - (b) 4.2절 정의로 혼동이 "유의하게 늘었다"가 아님
  - 두 조건 모두 (a)와 (b)를 만족하면 통과
  - 보조 보고: 변수별 하락, "변수 하나라도 ≥ 0.1" 읽기, CI_rel, oracle CI
- **S2** (조건마다)
  - (a) L_w(d8) > 회전 null 평균 + 2·SD. null 분포는 회전 10개 × 시드 2개다.
  - (b) 초과 국소성 Lexc = L_w − L_w(회전 null)일 때 상대 하락 ΔL = [Lexc(256) − Lexc(8)] / Lexc(256)
    - 상대 해상도 손실 ΔR = [R̄²_Δ(256) − R̄²_Δ(8)] / R̄²_Δ(256)(해석 가능 변수 평균)
    - ΔL ≤ 0이거나 ΔL < ΔR이면 만족
  - 학습 전 null도 보고한다.
- **S3** (조건마다): ρ = Spearman(상대 해상도 손실_i, −share_i) ≥ 0.6(해석 가능 변수). 좁은 구분일수록 많이 잃으면 양수다.
- **S4** (조건마다, 변별력 조건 충족 시)
  - drop_정밀 = 성공률_정밀(256) − 성공률_정밀(8), drop_거친도 같은 식
  - 통과: drop_정밀 ≥ 2·drop_거친이고 drop_정밀 ≥ 0.10
  - 해석 플래그(균일 열화 null)
    - w256의 과제별 오차 3종(에이전트, 상자, 각도)에 스칼라 k를 곱해 d8의 거친 성공률을 재현하는 k를 찾는다.
    - 그 k에서 예측되는 정밀 성공률 하락보다 관측 하락이 크지 않으면 "임계값 효과로 설명됨"으로 표시한다. 임계값 기반 성공률은 균일한 오차 증가에도 좁은 허용 오차 쪽에서 더 크게 떨어지기 때문이다.
- **판정 규칙**
  - 있음: S1과 S2 통과
  - 조건부 있음: 한 조건에서만 S1(a)(b)와 S2(a)(b)가 모두 성립. 또는 두 조건 모두 S1(b)·S2는 성립하지만 S1(a)가 실패(압착이 덜 묾)
  - 있음(다른 방향, packing): 압착이 문(S1(a) 성립) 조건 하나 이상에서 혼동이 유의하게 늘고 S2(b)가 실패
  - 그 외 없음
  - S3·S4는 해석 보강용이다.

## 7. 편차·중단 규칙

- 학습은 두 프로세스로 약 36분이 예상된다. pod 시간이 2.2시간에 가까워지면 진행 중인 단계를 멈추고, 그때까지 쓰인 JSON으로 판정한다.
- 분석 순서: 학습 → analyze(probe·혼동·국소성·분산 몫·합친 뉴런) → CEM. CEM은 예산이 $0.4 이상 남을 때만 한다.
- 분석 코드는 학습 중에 작성한다. 지표 정의는 이 문서가 기준이다. 구현 중 정의를 바꿔야 하면 결과를 보기 전에 10절에 시각과 이유를 적는다.

## 8. 위험 (사전 인지)

- MLP-only crush는 attention·residual로 우회할 수 있어 해상도가 거의 안 떨어질 수 있다. 그러면 S1(a)가 실패한다. 그 자체가 "우회로가 있으면 압착이 물지 않는다"는 결과다.
- 6,000 step에서 좁은 모델이 덜 수렴했을 수 있다. 3k와 6k의 loss 차이로 보고한다.
- 국소성 지표는 GT 가족 설계에 의존한다. 회전 null과 학습 전 null을 같은 가족으로 계산해 상대 비교한다.

## 10. 추가 기록 (본 실행 후 변경이 생기면 시각과 함께 여기에 적는다)

### 10.1 혼동 지표와 의미 거리 행렬 수정 (2026-10-21T08:46Z, 학습 진행 중, 판정 지표 계산 전)

- 상태: 학습 로그의 ID loss(3k step까지)만 봤다. probe·혼동·국소성·CEM 값은 본 데이터에서 한 번도 계산하지 않았다. 분석 코드 smoke는 5% 데이터로만 돌렸고 무의미한 값이었다.
- **발견한 confound.** 4.2절 정의(전 표본, 자기 값만 통제)로는 "무관 변수 의존"이 packing 없이도 생긴다.
  - 해상도를 잃은 모델의 probe 오차는 예측하지 못한 물리 변화 자체가 된다. 예: 에이전트 오차 ≈ −(1−β)·변위
  - 밀기 세계에서는 그 변화가 접촉을 통해 다른 변수와 물리적으로 묶여 있다. 밀 때 에이전트가 느려지고 상자가 움직이며, 고정된 상자를 밀면 에이전트가 멈추고, 회전은 접촉으로만 생긴다.
  - 그래서 거친(복사에 가까운) 모델은 표현이 섞이지 않아도 CI가 오른다. 이 경우 S1(b)는 packing이 아니라 해상도 손실을 잡는다.
- **수정(주 지표 v2)**
  - (1) 혼동 지수는 **상호작용 없는 시험 표본**에서만 계산한다. 조건: t와 t+1 모두 에이전트-상자 간격 > 1 px, 상자 이동 < 0.05 px, 회전 < 0.05°. 이 표본에서는 물리가 에이전트와 상자 변수를 묶지 않는다.
  - (2) 통제 = 자기 값 기저 + **자기 혁신 기저**. A는 변위 선형·RBF·크기를 추가한다. R·W는 이 표본에서 상자가 정지해 있어 자기 값만 쓴다.
  - (3) 변수와 무관 쌍: A의 오차 ~ {R, W}, R의 오차 ~ {A}, W의 오차 ~ {A}. CI = 세 부분 R²의 평균. 관련 대조: A ~ {B}, R ~ {B, W}, W ~ {B, R}
  - (4) 의미 거리 행렬 v2: A–S와 R–C를 1에서 0.5로 바꾼다. 상자 속도는 에이전트가 밀어서 생기고, 회전은 비중심 접촉으로 생기므로 물리적으로 연결되어 있다. 나머지 값은 그대로다. v2의 D̄ = 0.5, 균등 spread = 0.417
  - 유의성 규칙(bootstrap 95% 하한 > 0 그리고 ΔCI ≥ 0.02)과 S1~S4의 다른 세부는 그대로다.
- **보조 보고(v1)**: 08:22Z에 등록한 원래 정의도 같이 계산해 보고한다. 원래 정의는 전 표본, 원래 행렬, 자기 값 통제다. 판정에는 v2를 쓴다.
