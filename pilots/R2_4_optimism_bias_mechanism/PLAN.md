## 1. 질문

실패가 학습 데이터에 드물 때, 행동 조건 월드모델은 실패 결과를 전용 기전으로 표현하는가? 아니면 실패가 성공 회로의 약한 활성이나 offshoot로 얹혀(원문의 "semantic gravity": 희귀한 사실은 관련 회로 위의 작은 경로로 얹힌다) 성공 쪽으로 묻히는가? MiraBench는 정책 평가용 월드모델의 낙관 편향(실패를 성공으로 그림)을 보고했지만 기전은 "성공 prior"라는 가설로만 남겼다.

핵심 설계 원칙: **실패는 모델 입력(관측+행동)만으로 결정론적으로 예측 가능하다.** 따라서 낙관 편향이 생기면 그것은 aleatoric 불확실성이 아니라 학습 실패다.

## 2. 가설 (IDEAS_ROUND2.md 원문)

- H1: 학습 데이터의 실패율 p가 낮을수록 균형 시험 세트에서 낙관 편향 P(성공 예측 | 참 실패)가 커진다. 성공 사례의 오차는 거의 같다.
- H2: 낮은 p 모델에서는 실패 예측이 약한 활성에 의존한다. 약한 활성을 지우면 실패 예측 정확도만 크게 떨어진다.
- H3: 실패 예측에 기여하는 뉴런은 전용이 아니라 성공 예측 뉴런과 겹친다(같은 뉴런의 다른 강도·부호 영역). 실패 사례 20개로 미세조정하면 변화가 마지막 층에 모인다.
- 대립 설명(반드시 함께 보고): 낙관 편향이 단순 클래스 불균형으로 다 설명되고 손실 재가중(실패 업샘플링)이 이를 고친다면, 그 사실을 그대로 적는다.

## 3. 환경 (직접 작성, GPU 벡터화: `code/common.py`)

- 2D 측면 집어 들기, 지평 H=10 step, 완전 결정론
  - step 1–3: 그리퍼가 높이 gz0에서 옆으로 dx만큼 이동 (gx0 → gx0+dx)
  - step 4–5: 파지 높이 ZG=0.05로 하강, step 6: 닫기, step 7–10: L만큼 들어 올림 (step당 L/4)
- 정렬 오차 e = gx0 + dx − ox. 결과(입력으로 결정됨)
  - 성공: |e| < w 이고 미끄럽지 않음 → 물체가 그리퍼 x로 정렬된 뒤 함께 올라감(최종 물체 z = L)
  - 놓침(miss, 주 실패): |e| ≥ w → 물체가 제자리에 남음(최종 z = 0)
  - 미끄러짐(slip, 더 드문 두 번째 실패): 정렬됐지만 색 = 5(관측 가능한 "미끄러운" 색) → 2 step 올라갔다가 떨어짐(최종 z = 0)
- 입력 12차원: gx0, gz0, ox, w(물체 반폭), dx, L(행동), 색 one-hot 6개. 출력 40차원: step마다 그리퍼 x·z, 물체 x·z(절대 위치)
- 분포: ox ~ U[−1,1], w ~ U[0.05,0.15], gz0 ~ U[0.4,0.6], L ~ U[0.1,0.5], gx0 = ox + U[−0.4,0.4], 성공·놓침 물체의 색 ~ U{0..4}
- **데이터 수집 정책(실패율 p를 정하는 정렬 noise)**: 정렬 비율 r = |e|/w의 분포를 구간별 균등으로 둔다.
  - 확률 1−p: r ~ U[0,1) (성공), 확률 0.75p: r ~ U[1,2) (놓침), 확률 0.25p: 색 5 + r ~ U[0,1) (미끄러짐)
  - p ∈ {0.3, 0.1, 0.03, 0.01}. 모든 p에서 전이 수 N = 100,000으로 같다.
  - 같은 seed 안에서는 p가 달라도 장면 난수(ox, w, L, gx0, 부호, 색, r의 기본 난수)를 공유한다. 클래스 소속만 다르다(짝 설계).
  - Gaussian noise 대신 이 형태를 쓴 이유: Gaussian이면 p가 낮을 때 실패가 경계 바로 바깥에만 생기고, 균형 시험 세트의 먼 실패는 학습 지지 밖이 된다(OOD 외삽 교란). 구간 균등 정책은 모든 p에서 성공·실패의 조건부 분포와 지지가 같고 **빈도만** 다르다.

## 4. 모델과 학습 (`code/train.py`)

- MLP 4×256 GELU: 입력 → [Linear 256 → GELU] × 4 → Linear 40. LayerNorm 없음
- 입력·출력은 모든 조건에 공통인 정규화 통계(p=0.3 정책 표본 20만 개)로 표준화한다. 손실은 표준화된 출력의 MSE
- Adam(lr 1e-3, β=(0.9, 0.999)), warmup 200 step, cosine으로 1%까지 감소, batch 512, 유한 데이터셋(N=100k)에서 균등 표본추출
- 조건: p 4개 × {std, rw} × seed 3개(0, 1, 2) = 24개 모델을 한 GPU에서 batched 앙상블로 함께 학습한다. 같은 seed는 p와 조건에 관계없이 초기화가 같다.
  - std: 데이터 그대로
  - rw(기준 처방, 실패 업샘플링 = 손실 재가중): 매 batch의 50%를 실패에서 뽑는다(실패 안의 놓침:미끄러짐 비율은 자연 비율 3:1 유지)
- **학습 길이 T 규칙(보정, p=0.3 std 모델만 사용)**: T ∈ {5k, 10k, 20k, 40k} 각각으로 schedule을 끝까지 돈 p=0.3 모델(seed 3개)의 균형 시험 세트 성공 정확도와 실패 정확도 seed 평균이 모두 0.97 이상인 가장 작은 T. 없으면 40k. 의미: "실패가 흔한 통제 모델이 과제를 배운 시점"을 모든 p의 공통 예산으로 쓴다. 낮은 p 모델은 보정에 쓰지 않는다.
- (선택) 작은 transformer는 시간이 남을 때만 S1 지표에 한해 본다. 판정에는 쓰지 않는다.

## 5. 평가 세트와 지표

- 고정 시험 세트(seed 12345, 모든 모델 공통)
  - 균형 세트 bal: 성공 4096 + 실패 4096(놓침 3072: r ~ U[1,2), 미끄러짐 1024: 색 5, r ~ U[0,1))
  - 경계 근처 세트 near: r ~ U[0.8, 1.2], 색 0–4, 성공/놓침 약 50:50
- "들렸다고 예측" = 예측한 step 10 물체 z > L/2 (L은 그 사례의 명령 높이)
- **낙관 편향 opt** = 균형 세트 참 실패 중 들렸다고 예측한 비율 (놓침·미끄러짐 별도 보고). 연속판 opt_cont = 실패 사례에서 예측 최종 z / L의 평균
- 성공 정확도 acc_s = 참 성공 중 들렸다고 예측한 비율, 실패 정확도 acc_f = 1 − opt
- **성공 사례 오차** = 균형 세트 성공 사례의 40개 출력 MSE(원 단위). 물체 출력만의 MSE도 보고
- 경계 근처: 실패 쪽 opt, 성공 쪽 acc_s, 그리고 r 구간별 P(들렸다고 예측) 곡선
- 기준 처방(rw)의 opt와, 그 대가(성공 쪽 acc_s 하락)를 함께 보고한다.

## 6. 사전등록 판정 기준 (IDEAS_ROUND2.md 원문 + 채운 세부)

원문:
- S1: p=0.01 모델의 낙관 편향이 p=0.3 모델의 3배 이상이다. 성공 사례 오차 차이는 20% 이내다.
- S2: 낮은 p 모델에서, 성공 예측 정확도 하락이 2%p 이하인 α가 실패 예측 정확도를 20%p 이상 떨어뜨린다. 이 선택성은 p=0.3 모델보다 크다.
- S3: 실패 기여 상위 뉴런과 성공 상위 뉴런의 Jaccard가 무작위 기대값의 3배 이상이다. 미세조정 변화의 50% 이상이 마지막 층(또는 마지막 1/3)에 있다.
- 판정: S1과 (S2 또는 S3)를 만족하면 있음. S1만 만족하면 조건부: 단순 클래스 불균형과 구분되지 않음.

채운 세부(실행 전 고정):
- 공통: 모든 수치는 std 모델 seed 3개의 평균이다. 주 판정 모델은 p=0.01, p=0.03은 보조로 보고한다.
- S1
  - 비율 = opt(0.01) / max(opt(0.3), 0.01). 분모를 1%로 바닥 처리해 0에 가까운 분모로 비율이 터지는 것을 막는다(원 비율도 함께 보고).
  - 오차 차이 = |MSE_s(0.01) − MSE_s(0.3)| / MSE_s(0.3) ≤ 0.2 (방향과 무관한 대칭 기준).
- S2
  - 약한 활성 제거: 은닉 4층 모두에서 |a| < α·m_j인 GELU 출력(사후 활성)을 0으로 만든다. 층 순서대로 적용한다(앞 층 제거가 뒤 층 활성에 반영됨). m_j = 그 모델 학습 데이터 2만 개에서 잰 뉴런 j의 |a| 99.9 백분위수.
  - α 격자: {0.01, 0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5}. 정확도는 균형 세트에서 잰다.
  - D_s(α), D_f(α) = 제거 전 대비 성공·실패 정확도 하락(%p). 허용 α = D_s ≤ 2%p.
  - α* = 허용 α 중 p=0.01 모델의 D_f가 가장 큰 α. S2a: D_f(α*) ≥ 20%p.
  - 선택성 Sel = D_f − D_s. S2b: Sel_{p=0.01}(α*) > Sel_{p=0.3}(α*). S2 = S2a 그리고 S2b.
  - 대조(보조 조건, 판정과 별도로 보고): 층마다·표본마다 지운 개수를 맞춘 무작위 제거. 약한 활성 제거의 Sel이 무작위 제거보다 커야 기전 해석이 선다.
- S3
  - 실패 기여도: 짝 반사실 교환. 같은 장면에서 정렬 행동(r ∈ [0.05, 0.7], 성공)과 오정렬 행동(r ∈ [1.3, 1.9], 놓침, 같은 쪽) 512쌍. 뉴런 하나의 활성만 상대 실행의 값으로 바꿔 넣고(양방향), 들어 올림 readout R = Σ_{step 7–10} 물체 z의 변화를 잰다. 기여도 = 두 방향의 평균 |ΔR| / 평균 |R_성공 − R_실패|
  - 성공 기여도(주): 같은 장면·같은 정렬 행동에서 들어 올림 높이만 다른 쌍(L ∈ [0.35, 0.5] vs [0.1, 0.15])의 같은 교환. 즉 "물체가 그리퍼와 함께 올라간다"를 계산하는 뉴런. 보조: 성공 사례에서 뉴런을 0으로 만든 효과
  - top 집합 = 전체 1024개 은닉 뉴런 중 기여도 상위 10%(102개)
  - 무작위 기대값(주) = 두 집합의 층별 개수를 유지한 무작위 집합의 Jaccard 기대값(초기하분포, 4000회). 균일 무작위 기대값(102/(2·1024−102) ≈ 0.052)도 함께 보고. S3a: J / 기대값 ≥ 3
  - 미세조정: 학습된 p=0.01 std 모델에 새 놓침 실패 20개 + 자기 학습 데이터 재생 80개(전체 batch), plain SGD 300 step. lr은 {0.2, 0.1, 0.05, 0.02, 0.01, 0.005} 중 손실이 발산하지 않는(유한, 최종 < 처음, 최대 < 2×처음) 가장 큰 값(최적화 유효성 규칙)
  - 변화 비율(주) = 층별 ‖ΔW‖²+‖Δb‖²의 몫(선형층 5개: 은닉 W0–W3, 출력 W4). "마지막 층" = W4, "마지막 1/3" = W3+W4(깊이 5의 뒤 1/3에 걸친 두 층). S3b: W4 몫 ≥ 0.5 또는 W3+W4 몫 ≥ 0.5. S3 = S3a 그리고 S3b
  - SGD를 주 최적화기로 쓴 이유: Adam은 파라미터마다 갱신 크기를 정규화하므로 "변화의 위치"가 파라미터 수에 끌린다. SGD의 누적 변화는 손실 기울기가 실제로 가리킨 위치다. Adam(lr 1e-4) 결과도 보조로 보고한다.
- 판정
  - S1과 (S2 또는 S3) → 있음
  - S1만 → 조건부 있음: 단순 클래스 불균형과 구분되지 않음
  - S1 실패 → 없음(기전 지표는 참고로만 보고)
  - 별도 문장으로 반드시 적는다: rw가 p=0.01의 초과 낙관 편향(opt(0.01) − opt(0.3))을 몇 % 없앴는가. 75% 이상 없애면 "클래스 불균형으로 대부분 설명되고 재가중이 고친다"고 쓴다.

## 7. 기전 분석의 대조와 보조 측정 (PILOT_RULES 5장 필수 대조 포함)

- 뉴런 기저의 특별함: 무작위 회전 기저 null(층마다 고정 무작위 직교 행렬로 회전한 방향 단위 교환)과 학습 전(초기화) 모델 null에서 같은 Jaccard 비율을 잰다.
- 입력 복사 대조: 같은 장면에서 성공 행동 두 개(실패 쌍과 같은 |Δe|, 정렬 중심을 가로지름)의 교환. readout 변화가 없어야 하므로 이 교환의 기여도는 "행동 입력을 옮겨 적는 뉴런"의 몫이다. 실패 특이 기여도 = max(실패 기여 − 복사 기여, 0)로 다시 Jaccard를 잰다.
- 무관 회로 대조: 접근 높이 gz0만 다른 쌍(readout = step 1–5 그리퍼 z 합). 실패 상위 뉴런이 성공 뉴런과 겹치는 정도가 무관 회로와 겹치는 정도보다 큰지 본다(허브 뉴런 교란 점검).
- 두 번째 실패 모드(미끄러짐, 색 5): 미끄러짐 기여 상위 뉴런이 놓침 실패 뉴런·성공 뉴런(관련 회로)과 겹치는지, 무관 회로와 겹치는지 본다.
- 활성 영역(regime): 실패 교환의 쌍별 효과를 가중치로, 각 뉴런의 성공 실행 → 실패 실행 상태 전이를 {음극(z<0, GELU 음의 극), 약한 양(0 ≤ a < 0.1·m_j), 강한 양(a ≥ 0.1·m_j)} 3×3으로 나눠 실패 정보가 어디에 실리는지 본다. 영역별 제거(음극만, 약한 양만, 강한 양만)와 개수 맞춘 무작위 제거도 보고한다.
- 집중도: 기여도 합의 50%를 덮는 뉴런 수(실패 vs 성공).
- 미세조정 보조: 성공 사례 20개로 같은 미세조정(대조: 어떤 미세조정이든 출력 근처에 모이는가), 층별 활성 변화 몫, 첫 step 기울기 몫, 이식 회복률(미세조정된 층만 원 모델에 바꿔 끼웠을 때 놓침 정확도 향상의 회복 비율), 마지막 층만/마지막 2층만 미세조정했을 때의 효과(기전에서 나온 처방 후보).

## 10. IDEAS 대비 편차와 이유 (실행 전)

- 정렬 noise의 모양을 구간 균등 혼합으로 고정했다(3장 이유: 지지 일치).
- 두 번째 실패 모드를 넣었다(실패율의 25%, 관측 가능한 색). 과제 지시에 따른 선택 사항이다.
- 미세조정에 재생 표본 80개를 섞는다. 실패 20개만으로 학습하면 성공 예측 전체가 무너질 수 있어 "실패 20개를 데이터에 보태 계속 학습"하는 현실적 상황을 흉내 낸다.
- "마지막 1/3"은 선형층 5개 중 W3+W4로 정의했다(6장).
- (05:15Z 보완, 본 실행 전) 스모크 테스트(N=5k, 400 step, 판정과 무관한 미학습 모델)에서 **학습 전 모델의 Jaccard 비율도 약 5.6배**로 나왔다. 두 교환이 같은 readout(물체 z 합)을 쓰므로, readout으로 가는 하류 이득이 큰 뉴런이 두 top 집합에 함께 들어가기 때문이다. 회전 기저에서도 약 5배였다. 따라서 S3a(무작위 대비 3배)는 기전 없이도 통과할 수 있다. 판정 기준은 바꾸지 않고, 다음 보조 지표를 본 실행 전에 추가한다.
  - (i) 학습 전 null 대비: 학습된 모델의 J가 같은 seed의 학습 전 모델 J보다 큰가. S3a를 "기전 증거"로 읽으려면 J_trained > J_untrained여야 한다.
  - (ii) 이득을 뺀 표현 겹침: 교환 효과 대신 활성 변화량 평균 |a_실패 − a_성공| / m_j(성공 쪽은 |a_L높음 − a_L낮음| / m_j)로 top 10%를 고른 Jaccard. 학습 전 모델과 p=0.3 모델과 비교한다.
  - (iii) p 추세: semantic gravity가 맞다면 겹침은 p=0.01에서 p=0.3보다 커야 한다(J(0.01) > J(0.3)).
  - 판정 문장에는 S3a의 사전등록 결과와 함께 (i)~(iii)을 적는다.
