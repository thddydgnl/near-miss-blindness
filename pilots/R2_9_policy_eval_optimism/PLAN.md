## 1. 질문

월드모델로 정책의 성공률을 추정하는 정책 평가(Ctrl-World, WorldGym 계열)에서 다음을 시험한다.
- 희귀 실패 학습이 만든 낙관 편향이 정책 성공률의 **과대 추정**으로 나타나는가?
- 그 크기가 정책이 내는 near-miss의 비중을 따라가는가?
- 같은 고유 실패 수에서 "경계 양쪽 대비 쌍"이 재가중보다 이를 더 잘 고치는가?

R2-6의 한계(시각 버전이 PCA 특징 위의 MLP였음)를 넘어, 고정 DINOv2 patch token 위에서 미래 patch token을 자기회귀로 예측하는 DINO-WM식 latent 비디오 예측기를 쓴다.

## 2. 가설 (IDEAS_ROUND2.md 원문)

- H1: latent 비디오 월드모델로 상상 롤아웃을 하고 성공 판별기로 정책을 평가하면, 정책의 실제 성공률보다 높게 추정한다. 그 과대 추정은 near-miss를 많이 내는 정책에서 가장 크다.
- H2: 실패 개수를 고정하고 오래 학습하면 과대 추정이 준다. 예측기 MLP의 실패 검출 단위가 통합되는 것(n50 감소)과 함께 일어난다.
- H3 (처방): near-miss 대비 쌍이 같은 고유 실패 수의 재가중보다 과대 추정을 더 줄인다. 대비 쌍은 같은 시작 상태에서 정렬 오차만 경계 양쪽으로 다른 행동 쌍이다.

## 3. 세계와 월드모델

- **장면**: R2-4/R2-6의 집어 들기를 4단계 비디오로 바꾼다. 물체 중심 측면 카메라, 224×224, 박스 필터 anti-aliasing
  - f0: 그리퍼가 열린 채 (g, gz0)에 있다(g = 물체 대비 오프셋 ~ U[−0.25, 0.25]).
  - a1: 옆으로 dx 이동 → f1. 그리퍼가 정렬 오차 e = g + dx에 온다.
  - a2: ZG로 내려와 닫는다 → f2. |e| < w이면 물체를 잡는다(손가락이 물체 가장자리에서 멈추고 물체가 그리퍼 중심으로 옮겨짐). 아니면 손가락이 물체 옆에서 닫힌다.
  - a3, a4: L/2씩 들어 올린다 → f3, f4. 잡았으면 물체가 함께 올라가고(성공), 아니면 탁자에 남는다(실패).
  - 행동 벡터: (Δx, Δz, 닫기)
  - 실패는 입력(f0 + 행동)만으로 결정론적으로 정해진다. 미끄러짐 모드는 뺐다. R2-6에서 실패 모드가 섞이면 전체 편향 해석이 흐려졌기 때문이다.
- **인코더(고정)**: DINOv2 ViT-S/14
  - 224 px의 16×16 patch token을 2×2 평균 pooling해 8×8 = 64 token으로 줄인다.
  - token마다 PCA 64차원으로 줄인다(PCA는 별도 표본 800개 에피소드 × 5프레임에서 맞춤).
  - 토큰과 차원을 줄인 이유
    - 학습 프레임이 seed당 약 19만 장이라 저장(seed당 1.6 GB)과 예측기 계산을 한 GPU에서 감당해야 한다.
    - DINO-WM은 224 px에서 256 token × 384차원을 쓴다. 여기서는 공간 정밀도를 덜 잃도록 224 px로 추출한 뒤 pooling한다. 화면 가로 범위를 ±0.45로 좁혀 픽셀당 0.004 단위다(R2-6은 0.0054).
- **예측기(DINO-WM식)**
  - 구조: 프레임 token 64개 + 행동 token 1개 → 작은 ViT(pre-LN, 4 block, d=128, head 4, MLP 512, GELU) → 다음 프레임 token(잔차)
  - 학습: teacher forcing 1단계 MSE(정규화된 token), AdamW lr 3e-4, warmup 300, cosine, batch 256 전이, bf16 autocast
  - 상상: 실제 f0 token에서 4단계를 자기회귀로 굴린다. 직전 프레임 하나만 문맥으로 쓰는 Markov 예측기다(이 세계는 한 프레임에 상태가 다 보인다).
- **성공 판별기(고정)**
  - 실제 최종 프레임(f4) token을 입력받는 MLP(4096 → 256 → 1)
  - 학습 데이터: 시뮬레이터 라벨, r ~ U[0, 2) 에피소드 2만 개. 검증 2천 개
  - 모든 월드모델이 같은 판별기를 쓴다. 실제 f4에서의 정책별 판별 정확도도 함께 보고해, 판별기 오차와 월드모델 오차를 분리한다.

## 4. 데이터, 처방, 조건

- 학습 에피소드 N = 30,000(seed마다 다른 장면, 같은 seed 안에서는 p와 처방이 장면을 공유하는 짝 설계)
  - p=0.3: 성공 r ~ U[0,1), 실패 r ~ U[1,2), 실패 약 9천 개
  - p=0.03: 실패 약 900개 = 고정 고유 실패 수
- 처방(p=0.03, 고유 실패 약 900개로 같음)
  - std: 균일 표본추출
  - rw(균일 재가중): batch의 50%를 실패 에피소드(r ~ U[1,2))에서 뽑는다.
  - cp(near-miss 대비 쌍)
    - 실패 900개를 같은 장면의 near-miss(r ~ U[1.0, 1.2))로 바꾼다.
    - 같은 장면마다 경계 안쪽 성공(r ~ U[0.8, 1.0)) 하나를 짝으로 더한다. N을 지키려고 기본 성공 900개를 뺀다.
    - batch 구성: 25%는 near-miss 실패, 25%는 같은 단계의 그 짝 성공, 50%는 나머지 성공
  - nm(대조, near-miss 비짝)
    - cp와 같은 실패 900개와, 다른 장면의 경계 성공 900개로 구성한다.
    - batch 구성: near-miss 실패 25%, 비짝 경계 성공 25%, 나머지 50%
    - cp와 nm을 비교하면 "짝"의 효과만 분리된다.
- 학습 길이
  - T1 = 6,000 step. 규칙(사전 고정): p=0.3 std seed 0 모델을 T1로 학습한 뒤, 성공 512개·실패 512개 에피소드에서 상상 판별 정확도(균형 평균)를 잰다. 0.90 미만이면 T1 = 12,000으로 바꾼다. 결과는 8장에 본 실행 전에 기록한다.
  - 4× = 4·T1
- 조건(seed 3개, 0·1·2)
  - 주: p0.03_std_1x, p0.3_std_1x, p0.03_rw_1x, p0.03_cp_1x, p0.03_nm_1x, p0.03_std_4x
  - 보조: p0.03_cp_4x, p0.03_rw_4x

## 5. 평가와 지표

- **평가 정책 6개**: 같은 시작 장면 1024개에서 정책마다 정렬 비율 r = |e|/w를 뽑는다(부호 무작위).

| 정책 | r 분포 | 실제 성공률(기대) | near-miss 비중(기대) |
|---|---|---|---|
| π1 precise | \|N(0, 0.35²)\| | 99.6% | 약 0.4% |
| π2 good | \|N(0, 0.6²)\| | 90% | 약 5% |
| π3 medium | \|N(0, 0.9²)\| | 73% | 약 8% |
| π4 sloppy | \|N(0, 1.4²)\| | 52% | 약 8% |
| π5 far-failer | 50% U[0, 0.8), 50% U[1.5, 2.0) | 50% | 0% |
| π6 near-failer | 50% U[0, 0.8), 50% U[1.0, 1.2) | 50% | 50% |

  - π5와 π6은 실제 성공률이 같고 near-miss 비중만 정반대인 대조다.
- **과대 추정**(정책별) = 상상 성공률 − 시뮬레이터 실제 성공률. 상상 성공 = 판별기 logit > 0
  - 평균 과대 추정 = 6개 정책의 부호 있는 과대 추정 평균. 절대 오차 평균도 함께 보고한다.
- near-miss 비중 = 그 정책 에피소드 중 r ∈ [1.0, 1.2)인 비율. 정책 6개에서 near-miss 비중과 과대 추정의 상관을 보고한다.
- 정책별 보조 지표: near-miss 낙관(r ∈ [1, 1.2)에서 상상 성공), far-miss 낙관(r ≥ 1.5), 성공 사례 비관
- **경계 r***: 시작 장면 256개 × r ∈ {0.60, 0.65, …, 1.80}에서 상상 성공 확률이 0.5를 지나는 r(선형 보간)
- **예측기 n50**
  - 짝 64쌍: 같은 f0에서 정렬 행동(r ∈ [0.05, 0.7])과 오정렬 행동(r ∈ [1.3, 1.9])을 비교한다.
  - 예측기 MLP 은닉 단위(4층 × 512) 하나의 활성을, 상대 롤아웃의 같은 단계·같은 token 값으로 **모든 롤아웃 단계에서** 바꿔 넣는다(양방향).
  - readout은 고정 판별기 logit이다. 기여도 합의 50%를 덮는 단위 수를 n50으로 둔다.
  - 학습 전 예측기에서 같은 값을 재 null로 보고한다. 마지막 층 몫도 함께 보고한다.
- **성공 사례 예측 오차**
  - 실제 성공 에피소드 512개에서 실제 f0부터 4단계 자기회귀 상상을 한다.
  - 각 단계 실제 token과의 정규화 MSE를 평균한다. 실패 에피소드 오차도 함께 보고한다.

## 6. 사전등록 판정 기준 (IDEAS_ROUND2.md 원문 + 채운 세부)

원문:
- S1: p=0.03 1× 모델에서 정책 평가 과대 추정이 존재한다(평균 10%p 이상). near-miss 비중이 가장 높은 정책의 과대 추정이 가장 낮은 정책의 2배 이상이다.
- S2: 고유 실패 수를 고정하고 4배 학습하면 과대 추정이 상대적으로 30% 이상 줄고, n50도 준다.
- S3: near-miss 대비 쌍이 과대 추정을 50% 이상 줄이고, 같은 고유 실패 수의 재가중보다 더 줄인다. 성공 사례 오차 증가는 10% 이하다.
- 판정: S1과 S3를 만족하면 있음(처방 포함). S1과 S2를 만족하면 조건부(기전만). S1이 실패하면 없음.

채운 세부(모든 수치는 seed 3개 평균):
- S1
  - 모델: p0.03_std_1x. 평균 과대 추정 ≥ 0.10
  - 비율 = (near-miss 비중이 가장 높은 정책의 과대 추정) / max(가장 낮은 정책의 과대 추정, 0.01) ≥ 2. 분모 바닥은 1%p다.
  - 비중의 높고 낮음은 실제 평가 표본에서 잰다. 기대값 기준으로는 π6(50%)과 π5(0%)다.
- S2: p0.03_std_4x 대 p0.03_std_1x. (과대_1x − 과대_4x) / 과대_1x ≥ 0.30이고 n50_4x < n50_1x
- S3: p0.03_cp_1x
  - (과대_std1x − 과대_cp) / 과대_std1x ≥ 0.50
  - 과대_cp < 과대_rw(p0.03_rw_1x)
  - 성공 사례 예측 오차(cp) ≤ 1.10 × 성공 사례 예측 오차(std1x)
- 판정
  - S1과 S3 → 있음(처방 포함). S2도 만족하면 그렇게 적는다.
  - S1과 S2(S3 실패) → 조건부(기전만)
  - S1만 → 없음(현상만 재현). 원문 규칙이 비워 둔 경우라 이렇게 채웠다.
  - S1 실패 → 없음
- 함께 보고할 대조
  - (i) cp 대 nm: 짝 효과의 분리
  - (ii) π5의 far-miss 낙관: cp와 nm은 먼 실패를 보지 않고 학습하므로, 먼 실패에서 새 낙관이 생기는지 위험을 잰다.
  - (iii) 실제 f4에서의 판별 정확도
  - (iv) 학습 전 n50
