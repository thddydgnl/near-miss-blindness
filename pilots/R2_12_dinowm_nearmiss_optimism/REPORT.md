## 3. 해석

1. **공개 월드모델에서도 near-miss blindness는 있다. 다만 "낙관"이 아니라 "경계 해상도 손실"로 나타난다.**
   - DINO-WM PushT의 open-loop 상상에서 성공 대 near-miss AUROC는 0.97 → 0.88(H5) → 0.68(H10)로 떨어진다. 성공 대 far-miss는 0.99를 유지한다.
   - 상상 특징에 맞춰 학습한 판별기도 0.90에 그친다. 정보 자체가 사라진 것이다.
   - 상상 오차(전문가 행동열에서도 d_vis 0.11)가 성공과 near-miss의 실제 거리 차와 같은 크기다.
   - 작은 행동 교란의 효과가 상상에서 줄어든다(D1 감쇠 비 0.59). R2-9의 기전 후보("작은 차이가 상상에서 지워짐")와 맞는다.
2. **편향의 방향은 판정기를 어디서 보정했는지에 달렸다.**
   - 실제 프레임에서 보정한 판정기를 상상에 쓰면 상상 오차가 거리를 부풀린다.
     - 성공이 실패로 9~13%p 넘어가고, near-miss가 성공으로 6~10%p 넘어간다.
     - 순 편향은 비관(평균 −3~−7%p, H10 −25%p)이다.
   - 상상 롤아웃에 맞춰 보정한 판정기는 실무에서 월드모델 평가기를 만들 때 자연스러운 선택이다. 이 경우 R2-9 모양이 그대로 나온다.
     - near-miss가 많은 정책은 +10~11%p, far-failer는 0%p
     - near 비중과 과대 추정의 ρ = 0.97
   - R2-9의 큰 낙관(+46%p)은 실패 3% 데이터라는 성공 편중이 증폭한 것으로 보인다. DINO-WM PushT의 학습 데이터는 성공/실패 편중이 없는 무작위 밀기다. 그래서 공개 모델에서는 해상도 손실 성분만 남는다.
3. **정책 평가에의 함의**
   - 성공률이 비슷한 정책들의 비교에서 월드모델 평가는 실패 방식에 끌려간다.
     - 50% 수준 5개 정책의 상상 순위가 실제 순위와 정반대였다((b), τ = 0.14).
     - 상상 몫은 near 비중을 ρ = 0.76~0.91로 따른다.
   - 다만 크기가 5~13%p라, "같은 성공률이 98% 대 58%로 갈린다"는 R2-9 수준의 극적인 왜곡은 공개 모델·표준 벤치마크에서 재현되지 않았다.
   - 논문 주장으로는 다음이 더 정확하다. "월드모델 평가기는 성공 경계 근처의 해상도를 잃고, 그 손실이 정책 순위를 실패 방식 쪽으로 기울인다. 낙관인지 비관인지는 판정기 보정과 학습 데이터의 성공 편중이 정한다."
4. **R2-9 → R2-12 축의 위치**
   - 외부 타당성은 "부분적으로 있음"이다.
   - near-miss 특이적 정보 손실은 공개 모델에서 강하고 견고하다: 구간이 겹치지 않고, train 분할과 3프레임 문맥에서 재현됐다.
   - 반면 "near-miss가 성공으로 상상된다"는 강한 형태는 판정기 (b)에서만, 그것도 지각 흐림과 섞여서 기준을 넘었다.

## 4. 위험과 한계

- **판정의 취약성**
  - S1은 (b)에서만 통과했다(0.383, 구간 하한 0.326). S2는 0.714로 문턱 0.7 바로 위다(정책 8개라 ρ는 0.024 간격).
  - (b)의 near-miss 판정에는 실제 프레임 지각 흐림(0.283)이 크게 섞였다.
  - S3의 τ 조항은 설계상(50% 수준 정책들의 실제 성공률이 거의 같음) 쉽게 만족된다. (b) τ의 bootstrap 구간 [0.18, 0.67]이 점추정 0.143을 포함하지 않는다. 50% 수준 5개의 순위가 완전히 뒤집힌 극단 배치라 분포가 치우쳤기 때문이다.
- **정책이 합성 교란이다.** 전문가 구간에 offset·iid·gross 교란을 넣은 것이라 학습된 정책의 실패 분포와 다르다. PushT 평가기는 agent 위치까지 성공 조건에 넣는다. 그래서 near-miss의 85%가 agent 위치 오차다. 물체(T 블록) 자세의 near-miss는 95개뿐이다.
- **판별기**
  - (a)는 train 분할의 넓은 교란 혼합으로 학습했다(실제 프레임 정확도 0.92~0.955).
  - 경계 근처(r ∈ [0.75, 1))의 실제 프레임 정확도는 0.69로, 판정기 자체가 경계에서 완벽하지 않다.
  - 상상 몫은 같은 궤적의 실제 프레임 판정과의 차이로 분리했다. 그래도 판정기와 상상의 상호작용(상상 특징의 분포 이동)은 완전히 떼어낼 수 없다.
- **표본**: val 궤적이 21개뿐이라 400 에피소드가 서로 상관되어 있다. cluster bootstrap으로 반영했고, 궤적 395개인 trainsplit에서 같은 결론을 얻었다.
- **모델 범위**: 체크포인트 하나(PushT), 과제 하나. TF32 + SDPA attention을 썼다(R2-1에서 원래 구현과의 차이 1e-4 수준으로 검증).
- **사후 분석**: 상상 몫 분해, D3 판별기의 정책 평가 사용, 3프레임 점검, AUROC 구간은 결과를 본 뒤 추가했다. 판정에는 쓰지 않았다.

## 5. 본 실험으로 키울 때의 다음 단계

1. **학습된 정책으로 바꾼다.** PushT diffusion policy를 여러 학습 단계 checkpoint와 seed로 준비해 실제 실패 분포를 만든다. 같은 DINO-WM 평가를 한다. 정책 개선이 near-miss 비중을 늘리는 구간에서 평가 순위가 어떻게 기우는지 본다. 목표 조건은 DINO-WM 규약(dset 목표)과 표준 PushT 목표(고정 T 영역, coverage 기준)를 둘 다 쓴다.
2. **성공 편중의 인과 시험(R2-9 기전의 공개 모델 판).** DINO-WM PushT 예측기를 성공 편중 데이터(목표 도달 구간 97%)와 균형 데이터로 짧게 미세조정한다. 같은 정책 집합에서 "해상도 손실"이 "낙관"으로 바뀌는지 본다. 예상 비용 $2~4.
3. **평가 지표와 처방**
   - 상상 특징의 성공 대 near-miss AUROC를 월드모델 평가기의 경계 해상도 지표로 제안한다(정보량 상한으로 D3 판별기도 함께 쓴다).
   - DINO-WM 예측기의 dropout(0.1) MC 표본이나 앙상블 분산으로 경계 근처 상상을 표시하고, 성공 추정을 할인하는 처방을 시험한다.
4. **horizon 곡선.** H 3·5·7·10에서 AUROC와 비관·낙관 몫을 재서 평가가 경계 근처에서 무의미해지는 horizon을 정한다. H10은 이미 AUROC 0.68이다.
5. **물체 중심 판정.** block 자세만으로 정의한 성공 조건에서 같은 분석을 반복해, agent 위치 near-miss와 물체 near-miss를 분리한다. block near-miss 표본을 늘리는 정책 설계가 필요하다.
