## 1. 질문과 배경

R2-4 → R2-6 → R2-9의 B축 결과: 성공 위주 데이터로 학습한 행동 조건 월드모델은 경계 바로 바깥의 near-miss 실패를 성공으로 상상한다. R2-9(직접 만든 장면·직접 학습한 DINO-WM식 예측기)에서는 실제 성공률이 거의 같은 두 정책이 상상에서 98.5% 대 58.0%로 갈렸고, 정책 6개에서 near-miss 비중과 과대 추정의 상관이 r = 0.95였다.

**질문.** 공개 체크포인트와 표준 벤치마크(DINO-WM PushT)에서도 near-miss 실패가 성공으로 상상되는가? 그 결과 월드모델 기반 정책 평가가 실패 방식에 따라 왜곡되는가?

## 2. 가설

- H1: DINO-WM PushT로 정책의 행동열을 open-loop 상상하고 예측 최종 특징에서 성공을 판정하면, near-miss 실패(최종 오차가 문턱의 1~2배)는 far-miss 실패(3배 이상)보다 훨씬 자주 성공으로 판정된다.
- H2: 그 결과 정책별 과대 추정(상상 성공률 − 실제 성공률)이 near-miss 비중을 따라간다.
- H3: 실제 성공률이 같은 정책들이 상상에서는 크게 갈리고, 상상 순위가 실제 순위와 어긋난다.

## 3. 설계

### 3.1 모델과 환경
- DINO-WM PushT 공개 체크포인트(고정, OSF `outputs/pusht`, DINOv2 ViT-S/14 frozen, num_hist 3, frameskip 5). R2-1의 설치·로딩 코드(`code/r21lib.py`, 변경 없이 복사)를 쓴다. 예측기 attention은 R2-1에서 검증한 SDPA 교체(수학적으로 같음), TF32.
- PushT 시뮬레이터(DINO-WM `PushTWrapper`, with_velocity, with_target). 참 성공은 PushT 평가기 `eval_state`: 위치 차(agent xy + block xy 4차원 norm) < 20 그리고 각도 차 < π/9.
- **최종 오차 비 r = max(위치 차/20, 각도 차/(π/9))**. 성공 ⟺ r < 1. 모든 궤적에 r과 성분(agent 거리, block 거리, 각도)을 기록한다.
  - 구간: 성공 r < 1, **near-miss 1 ≤ r < 2**, mid 2 ≤ r < 3, **far-miss r ≥ 3** (IDEAS 정의 그대로; 경계는 왼쪽 닫힘)

### 3.2 에피소드(시작·목표)
- DINO-WM의 `goal_source='dset'`과 같다: 데이터셋 궤적의 임의 offset에서 상태 s0를 잡고, 데이터셋 행동 H×5 env step(전문가 구간)을 시뮬레이터로 재생한 결과를 목표로 한다. 전문가 구간 자체는 r = 0.
- 본 평가 집합 `main`: **val 분할**(궤적 21개, 길이 76~167), H = 5(goal_H 5, 25 env step), 에피소드 400개(seed 303). 월드모델이 학습에서 본 전문가 행동열이 아니다.
- 상상 시작 관측: s0에서 렌더링한 1프레임(시각 + proprio), DINO-WM 계획과 같다. 실제와 상상이 같은 시작 관측과 같은 행동열을 쓴다.

### 3.3 정책 (8개, 시뮬레이터만으로 보정)
행동은 상대 변위(env 단위 = world px/100). 정책은 전문가 구간에 교란을 넣어 만든다(IDEAS 예시 "목표 도달 행동열에 크기를 달리한 교란").
- 교란 종류: `offset`(에피소드마다 고정 방향 u, 크기 β ~ U(0, β_max)의 지속 편향 → 경계 근처 실패), `iid`(단계마다 N(0, σ²) 잡음), `gross`(큰 잡음 σ_big, far-miss를 만든다), `mix`(확률 q로 gross, 아니면 offset(β_max) 또는 clean(σ 1))
- 보정 규칙: val 분할 보정 에피소드 400개(seed 101)에서 크기 격자를 돌리고 목표 성공률을 선형 보간으로 맞춘 뒤, 새 에피소드 400개(seed 102)로 확인했다. σ_big은 P(r ≥ 3 | 교란) ≥ 0.9인 최소 격자값(H5: 60).
- 정책 집합(H5, 확인 집합 수치)

| 정책 | 정의 | 목표 성공률 | 확인: 성공 / near / mid / far |
|---|---|---|---|
| far_L | mix q=0.496, clean(σ 1), σ_big 60 | 0.50 | 0.527 / 0.007 / 0.015 / 0.450 |
| mixA_L | mix q=1/3, offset β_max 2.34 | 0.50 | 0.517 / 0.147 / 0.007 / 0.328 |
| mixB_L | mix q=1/6, offset β_max 3.05 | 0.50 | 0.465 / 0.295 / 0.043 / 0.198 |
| near_L | offset β_max 3.5 | 0.50 | 0.500 / 0.415 / 0.075 / 0.010 |
| iid_L | iid σ 7.06 | 0.50 | 0.487 / 0.430 / 0.050 / 0.033 |
| far_H | mix q=0.244, clean, σ_big 60 | 0.75 | 0.698 / 0.000 / 0.018 / 0.285 |
| near_H | offset β_max 2.34 | 0.75 | 0.760 / 0.225 / 0.007 / 0.007 |
| iid_H | iid σ 4.71 | 0.75 | 0.800 / 0.185 / 0.003 / 0.013 |

- 성공률 50% 수준 5개는 near-miss 비중이 0.7% → 43%로 단계적으로 다르다(S2·S3의 핵심 대비). 75% 수준 3개는 순위 시험용이다.
- 대조 정책 `expert`(전문가 구간 그대로, r = 0)를 에피소드마다 함께 돌린다. 정책 집합(S2·S3)에는 넣지 않는다.

### 3.4 상상과 성공 판정
- 상상: 같은 시작 관측(1프레임)과 같은 행동열(정규화, 5 step × 10차원)로 `VWorldModel.rollout`을 open-loop로 굴려 마지막 예측 프레임의 시각 특징 ẑ(196×384)과 proprio 임베딩을 얻는다.
- 판정은 모두 목표 조건부다(PushT의 성공은 에피소드마다 다른 목표에 대한 것). 목표 특징 z_g는 실제 목표 프레임의 인코딩.
  - **(a) 판별기**: 실제 최종 프레임의 DINOv2 patch 특징 z와 z_g를 입력받는 작은 transformer(token [z, z_g, z−z_g] → 2층 d=128 → CLS). 참 성공 라벨로 학습(BCE, 클래스 균형) + 보조로 참 log r 회귀(같은 참값). 학습 후 고정, 문턱 0.5.
  - **(b) 목표 latent 거리 문턱**: d_vis = mean (z − z_g)²(patch·채널 평균, DINO-WM 계획 비용의 시각 항). 문턱 τ는 실제 프레임에서 균형 정확도를 최대로 하는 값.
  - (b2, 보조) DINO-WM 계획 objective(시각 MSE + α·proprio 임베딩 MSE, α = 1). 문턱은 같은 방식. 판정에는 쓰지 않는다.
- 판별기 학습 집합: **train 분할** 에피소드 2000개(H5 1400, H10 600) × (전문가 + 교란 7개 = 8) = 16,000 궤적. 교란은 iid/offset/scale/gross를 0.35/0.35/0.15/0.15로 섞고 크기는 50% 성공 크기의 0.3~3배(로그 균등). 에피소드 20%는 held-out.
- 판별기 선택 규칙(사전): held-out 균형 정확도가 가장 좋은 epoch. (a)의 held-out 정확도가 0.90 미만이면 큰 변형(d 256, 4층)도 학습해 held-out 균형 정확도로 고른다. (b) 문턱은 학습 부분에서 정한다.
- 실제 프레임 정확도는 두 곳에서 보고한다: 판별기 held-out(train 분할), 평가 집합의 실제 최종 프레임(정책별, r 구간별).

## 4. 지표

평가 집합의 각 궤적 i(정책 π, 에피소드 e)에 대해 r_i, 구간, 판정 j ∈ {a, b, b2}의 상상 판정 Ŝ_ij와 실제 프레임 판정 S̃_ij를 기록한다.

- M1 (궤적 단위, 8개 정책의 궤적 전체를 합침, expert 제외)
  - P(Ŝ = 1 | near-miss), P(Ŝ = 1 | far-miss), 그 비. 함께: P(Ŝ = 1 | 성공)(상상 민감도), P(Ŝ = 1 | mid)
  - 같은 값을 실제 프레임 판정 S̃로도 계산한다(지각 기준선)
  - r 구간별 곡선 P(Ŝ = 1 | r)(그림 2)
- M2 (정책 단위): 실제 성공률 s_π, 상상 성공률 ŝ_π, **과대 추정 o_π = ŝ_π − s_π**, **near-miss 비중 n_π = P(1 ≤ r < 2)**(정책의 전체 궤적 중). 8개 정책에서 Spearman(n_π, o_π), Pearson도 함께
- M3: 실제 성공률 차이 ≤ 5%p인 정책 쌍의 상상 성공률 차이 최댓값. 상상 순위와 실제 순위의 Kendall τ(τ-b, 8개 정책)
- 불확실성: val 궤적(21개) 단위 cluster bootstrap 1000회의 95% 구간

## 5. 진단과 대조 (사전등록, 판정에는 쓰지 않음)

- D1 감쇠: 같은 에피소드의 상상 전문가 ẑ_expert 대비 상상 편차 d_vis(ẑ_π, ẑ_expert)와 실제 편차 d_vis(z_π, z_g)의 비를 r 구간별 중앙값으로 본다. 1보다 작으면 상상이 작은 편차를 줄인다(near-miss blindness의 기전 후보).
- D2 입력 복사 대조: ẑ = z_start(아무 일도 없다는 예측)일 때의 판정. 행동을 무시하는 평가기가 내는 값이다.
- D3 정보량: (a_imag) 상상 특징으로 학습한 판별기(같은 구조·학습 규칙, 참 라벨). 상상 특징에 near-miss를 가를 정보가 남아 있는지 본다. 성공 대 near-miss AUROC를 실제·상상·a_imag로 비교한다.
- D4 near-miss의 구성: agent 위치 오차가 주인지 block 자세 오차가 주인지에 따라 P(Ŝ = 1 | near)를 나눠 본다.
- 보조 평가 집합(판정에 쓰지 않음)
  - `H10`: val 분할, H = 10(50 env step), 에피소드 300개(seed 304), 정책은 같은 규칙으로 H10에서 보정(`policies_H10.json`). 상상이 길수록 blindness가 커지는가
  - `trainsplit`: train 분할(판별기 학습 집합과 궤적이 겹치지 않게), H = 5, 에피소드 400개(seed 305). 월드모델이 학습에서 본 전문가 행동열 근처에서 낙관이 더 큰가(기억 효과)
- CEM-MPC 정책은 하지 않는다(8절 편차 1).

## 6. 사전등록 판정 기준 (IDEAS_ROUND2.md R2-12 원문)

- S1: P(상상 성공 | near-miss 실패)가 0.3 이상이고, far-miss의 3배 이상이다. 판정 (a)와 (b) 중 하나 이상에서 성립해야 한다.
- S2: 정책 4개 이상에서 near-miss 비중과 과대 추정의 Spearman이 0.7 이상이다.
- S3 (권장): 실제 성공률 차이가 5%p 이내인 정책 쌍에서 상상 성공률 차이가 20%p 이상이다. 또는 상상 순위와 실제 순위의 Kendall τ가 0.8 이하다.
- 판정
  - S1과 S2를 만족하면 있음: B축 현상이 공개 월드모델에서도 성립
  - S1만 만족하면 조건부
  - S1이 실패하면 없음(장면·모델 특이적이었음)

### 6.1 채운 세부(기준값은 바꾸지 않음)
- 판정은 본 평가 집합 `main`(val, H5, 400 에피소드 × 8 정책)으로 한다. `H10`, `trainsplit`은 보조다.
- S1: 판정 (a)와 (b)를 각각 본다. far-miss 확률이 0이면 비 조건은 성립으로 본다(near ≥ 0.3이면 통과).
- S2·S3는 S1을 만족한 판정 방식에서 본다. 둘 다 S1을 만족하면 어느 하나에서 성립하면 통과로 하고 두 값을 모두 보고한다. S1이 둘 다 실패하면 S2·S3는 (a) 기준으로 보고만 한다.
- S2의 정책 수는 8개(3.3절). S3의 "정책 쌍"은 8개 정책의 모든 쌍 중 실제 성공률 차이 ≤ 5%p인 쌍.
- 해석 규칙(판정 등급은 바꾸지 않고 판정문에 단서로 붙인다)
  - 지각 단서: 같은 판정 방식의 실제 프레임 P(S̃ = 1 | near)가 상상 값과 0.10 이내이면, near-miss 성공 판정은 상상보다 판정기의 지각 흐림에서 온 것으로 적는다.
  - 비관 단서: P(Ŝ = 1 | 성공) < 0.5이면, 그 판정 방식은 상상 특징에서 전반적으로 비관적이라고 적는다(분포 이동).

## 8. 편차와 이유

1. 정책: IDEAS의 두 예시 중 CEM-MPC 대신 교란 기반 정책만 쓴다. DINO-WM으로 계획한 정책을 같은 DINO-WM으로 평가하면, 계획기가 고른 행동열이 상상에서 성공하도록 선택된 것(optimizer's curse)이 near-miss 효과와 섞인다. 교란 정책은 월드모델과 독립이고 실패 방식을 직접 조절할 수 있다.
2. 시작 관측은 DINO-WM 계획과 같은 1프레임이다(예측기는 frame-causal이라 1프레임 문맥도 학습 분포 안이다).
3. 판별기는 목표 조건부다. R2-9는 목표가 고정이라 최종 프레임만 넣었지만 PushT는 에피소드마다 목표가 다르다.
4. (b) 문턱은 정확도 대신 균형 정확도 최대화로 정한다(판별기 학습 집합의 클래스 비율에 덜 민감).
