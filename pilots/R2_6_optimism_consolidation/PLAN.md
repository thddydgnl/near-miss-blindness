## 1. 질문과 배경

R2-4의 사후 분석에서 다음 그림이 나왔다. 실패가 흔하면 소수 뉴런이 마지막 은닉층에서 "놓침 검출기"로 통합된다(n50 ≈ 5, 성공에서 꺼지고 실패에서 강하게 켜짐). 실패가 드물면 검출기가 없다. 실패 정보는 강한 활성의 등급 변조로 퍼져 있고(n50 ≈ 60), 결정 경계가 성공 쪽으로 밀린다(낙관 편향). 이 관계를 원인 조작으로 다시 시험한다.
- 고유 실패 수를 고정하고 학습 길이를 바꾼다.
- 학습 길이를 고정하고 고유 실패 수를 바꾼다.
- 통합된 검출기를 직접 지운다.
- 시각 입력 버전에서도 확인한다.

## 2. 가설 (IDEAS_ROUND2.md 원문)

- H1 (경계 팽창): 낙관 편향은 near-miss 실패에 집중되고, 예측 경계 r*가 p에 따라 바깥으로 이동한다.
- H2 (통합이 원인): 실패 개수를 고정하고 학습 길이만 바꾸면, 검출기 통합(n50 감소, 마지막 층 몫 증가)이 편향 감소보다 먼저 또는 함께 일어난다.
  - 학습 길이를 고정하고 고유 실패 수만 바꿔도 같은 관계가 나온다.
  - 개입으로 검출기를 지우면(통합된 소수 뉴런 ablation) 편향이 되살아난다.
- H3 (전용 단서 면역): 같거나 더 낮은 빈도에서도 전용 관측 단서가 있는 실패는 편향이 near-miss 편향의 1/3 이하다.
- H4 (처방): 경계 근처 near-miss 예제를 반복 노출하는 hard-example 재샘플링이, 균일 재가중보다 같은 고유 실패 수에서 편향을 더 줄인다.

## 3. 두 버전

- **상태 버전**: R2-4 그대로. 입력 12차원(gx0, gz0, ox, w, dx, L, 색 one-hot), 출력은 10 step의 그리퍼·물체 위치 40차원
- **시각 버전(필수)**
  - 같은 장면의 초기 상태를 물체 중심 측면 카메라로 렌더링한다(224×224, 박스 필터 anti-aliasing).
    - 그리는 것: 탁자, 물체(폭 2w, 색), 그리퍼(손바닥, 손가락 둘, 손목 표시)
    - 가로 범위는 물체 기준 ±0.6, 세로 범위는 −0.08~0.80
  - 인코더: 고정 **DINOv2 ViT-S/14** patch token(16×16×384)
    - 이 PCA를 patch마다 32차원으로 줄인다(PCA는 p=0.3 정책 표본 4096장의 token에서 한 번 맞춤). 결과는 8192차원 관측이다.
    - 여기에 행동(dx, L)을 붙여 같은 MLP 4×256 GELU에 넣는다.
  - 출력은 물체 기준 상대 궤적(x 좌표에서 ox를 뺌)이다. 물체 중심 카메라에서는 ox가 보이지 않기 때문이다. 판정에 쓰는 물체 z 출력은 상태 버전과 같다.
  - DINOv2를 고른 이유
    - latent 월드모델(DINO-WM)이 쓰는 표준 고정 인코더라 피지컬 AI 관련성이 높다.
    - 렌더링과 특징 추출을 한 번만 하면 되어 싸다. 학습은 특징 위에서 batched로 한다.
    - 작은 CNN을 끝단까지 학습하면 이미지 저장과 학습 비용이 크다. 또 R2-4처럼 여러 조건을 한 GPU에서 묶어 돌리기 어렵다.
  - 시각 버전의 위험: 정렬 경계 근처는 1~5 px 차이라 DINOv2 patch(14 px) 특징이 위치를 충분히 담지 못할 수 있다.
    - 스모크에서 이 위험을 본다. 다만 결과 판정에 쓰는 낮은 p 모델은 보지 않는다.
    - 대체 규칙: 시각 p=0.3 1× std 모델의 균형 세트 실패 정확도가 0.85 미만이면 PCA 차원을 64로 올리고, 그 사실을 본 실행 전에 기록한다.

## 4. 조건 격자와 학습

- 데이터 정책, 시험 세트, 정규화는 R2-4와 같다. T = 10k step(1×), 40k step(4×), batch 512, Adam lr 1e-3, cosine
- 처방 3종: std(그대로), rw(균일 재가중: batch의 50%를 실패에서), hn(near-miss hard-example 재샘플링)
  - hn의 batch 구성: 성공 50%, 실패 균일 25%, near-miss 실패(놓침, r < 1.2) 25%
  - rw와 hn은 같은 고유 실패 집합을 쓴다. r은 시뮬레이터가 주는 정렬 비율이다(오라클 near-miss 라벨).
- 상태 버전(seed 3개, 모든 조건에 std/rw/hn, 1×/4×)

| s_n20k_T1 / T4 | 0.01 | 20k | 200 |

## 5. 지표

- 균형 시험 세트(성공 4096 + 놓침 3072 + 미끄러짐 1024), 경계 근처 세트(r ∈ [0.8, 1.2)), 시각 버전은 같은 장면을 렌더링한 것
- "들렸다고 예측" = 예측 step 10 물체 z > L/2
- 편향 opt = 참 실패 중 들렸다고 예측한 비율
  - near-miss 편향: 놓침 중 r ∈ [1.0, 1.2)
  - far-miss 편향: 놓침 중 r ∈ [1.5, 2.0)
- 결정 경계 r*: r 구간별 P(들렸다고 예측) 곡선(균형 세트 0.1 간격 + 경계 세트 0.025 간격)이 0.5를 지나는 지점(선형 보간). seed마다 구한 뒤 평균한다.
- 실패 교환 기여도와 n50(R2-4와 같음)
  - 512쌍의 같은 장면에서 정렬 행동(r ∈ [0.05, 0.7])과 오정렬 행동(r ∈ [1.3, 1.9])을 비교한다.
  - 뉴런 하나의 활성을 양방향으로 바꿔 넣고, 들어 올림 readout(Σ step 7–10 물체 z)의 변화를 잰다.
  - n50 = 기여도 합의 50%를 덮는 뉴런 수. 마지막 층 몫 = 은닉 4층 중 마지막 층의 기여도 몫
- readout 이득 교란 점검(R2-4 교훈)
  - n50_dact: 이득을 뺀 집중도. 활성 변화 |a_실패 − a_성공|/m_j 기준
  - 학습 전 모델의 n50
  - 실패·성공 상위 10% 겹침: 이득 포함 버전과 이득 제거 버전을 모두 재고, 각각 학습 전 null과 비교한다.
- 검출기 ablation
  - 대상: 실패 교환 기여도 상위 n50개 뉴런(그 모델 자신의 n50)
  - 방법(주): 각 뉴런을 학습 데이터 평균 활성으로 바꾸는 mean-ablation. 0 대체도 보조로 보고한다.
  - 대조: 층별 개수를 맞춘 같은 수의 무작위 뉴런(검출기 제외, 20회 평균)
  - 측정: 균형 세트 opt
- 성공 사례 오차 = 균형 세트 성공 사례의 40개 출력 MSE

## 6. 사전등록 판정 기준 (IDEAS_ROUND2.md 원문 + 채운 세부)

원문:
- S1: 상태·시각 두 버전 모두에서 p=0.01 모델의 near-miss 편향이 far-miss 편향의 3배 이상이고, r* 이동이 반폭의 20% 이상이다.
- S2: 고유 실패 수를 고정한 짝에서 학습을 4배로 늘리면 n50이 줄고 편향이 상대적으로 30% 이상 준다. 이 조건이 상태 버전 3개 설정 중 2개 이상과 시각 버전 1개 이상에서 성립해야 한다. 또 체크포인트 시계열에서 n50 감소가 편향 감소보다 늦지 않다.
- S3: 통합된 검출기 뉴런(상위 n50개)을 ablation하면 편향이 낮은 p 수준의 50% 이상으로 되살아난다. 비교 대상인 같은 수의 무작위 뉴런 ablation은 그 1/3 이하여야 한다.
- S4 (권장): 같은 고유 실패 수에서 near-miss 재샘플링이 균일 재가중보다 편향을 더 줄인다(상대 30% 이상 차이). 성공 오차 증가는 10% 이하다.
- 판정: S1과 S2와 S3를 만족하면 있음("낙관 편향은 실패 검출기 통합 전의 상태"). S1과 (S2 또는 S3)를 만족하면 조건부. 그 외는 없음.

채운 세부(실행 전 고정, 모든 수치는 seed 3개 평균):
- S1
  - 모델: 각 버전의 N=100k, 1×, std, p=0.01. 비율 = opt_near / max(opt_far, 0.01)(분모 1% 바닥) ≥ 3
  - r* 이동 = r*(p=0.01) − r*(p=0.3) ≥ 0.2(같은 버전·N·T·std). p=0.3 모델을 기준점으로 써서, 지각 오차처럼 p와 무관한 경계 치우침을 뺀다.
  - 두 버전 모두 두 조건을 만족해야 통과
- S2
  - 상태 버전 "3개 설정" = p=0.01에서 N_f ≈ 200 / 1k / 3k(N = 20k / 100k / 300k). 시각 버전 설정 = p=0.01, N=100k(N_f ≈ 1k)
  - 짝 조건: 같은 설정의 1×와 4× std 모델에서 n50(4×) < n50(1×) 그리고 (opt(1×) − opt(4×)) / opt(1×) ≥ 0.30
  - 시계열 조건: 그 설정의 4× std 실행 snapshot(2.5k 간격 중 5k 이상) seed 평균 곡선으로 판단한다.
    - n50과 opt 각각의 반감 시점을 잰다. 반감 시점 = 최댓값 이후 처음으로 "끝값 + 0.5×(최댓값 − 끝값)" 이하가 되는 step
    - t_half(n50) ≤ t_half(opt)이어야 한다. n50이 줄지 않으면(최댓값 ≤ 끝값) 실패
  - 설정 하나가 "성립"하려면 짝 조건과 시계열 조건을 모두 만족해야 한다. S2 = 상태 2개 이상 그리고 시각 1개 성립
- S3
  - 주 모델: 상태 버전 N=100k, p=0.01, 4×, std(학습 연장으로 통합된 모델)
  - "낮은 p 수준" L_low = 같은 N의 p=0.01, 1×, std 모델의 opt
  - 되살아남의 비율 = (opt_검출기제거 − opt_기본) / (L_low − opt_기본) ≥ 0.5
  - 무작위 대조: (opt_무작위제거 − opt_기본) ≤ (opt_검출기제거 − opt_기본) / 3
  - L_low ≤ opt_기본이면(통합으로 편향이 줄지 않았으면) 실패
  - 보조 보고: p=0.3 1× 상태 모델, 시각 버전의 같은 두 모델, N=20k·300k의 4× 모델
- S4
  - 주 설정: 상태 버전 N=100k, p=0.01, 1×(N_f ≈ 1k)
  - (opt_rw − opt_hn) / opt_rw ≥ 0.30이고, 성공 MSE(hn) ≤ 1.10 × 성공 MSE(rw)
  - 성공 오차 비교의 기준을 rw로 둔 이유: 둘 다 같은 고유 실패를 재사용하는 처방이다. hn이 rw보다 성공을 더 희생하는지를 본다. std 대비 증가도 함께 보고한다.
  - 보조: N_f 200·3k, 4×, 시각 버전
- H3(판정 외 보고): p=0.01 1× std에서 opt_slip ≤ opt_near / 3인지 두 버전에서 본다.
