### 0.4 분석 계획 (v1.1 주 칸 정의를 따름)
- **판정 Ŝ**
  - (a): logit > 0. 상상은 들어 올리기 뒤 상상 프레임, 실제는 실제 들어 올리기 뒤 프레임
  - (c): V > 0.5. 상상은 k번째 청크 끝 V(`v_end`), 실제는 실제 끝 상태 V(`v_real_k1`). `v_lift`는 보조로 보고한다.
  - (d): P(Yes) > 0.2018. 이 문턱은 E0b에서 학습 분할로 고정했다. 보조라 점수(AUROC)가 주이고, 비율은 기술로만 낸다.
- **참값**
  - 성공은 `success_settled`(정착 상태 LIBERO 술어)다.
  - 실패 구간은 `r_settled`로 나눈다: near 1 ≤ r < 2, mid 2 ≤ r < 3, far r ≥ 3.
  - r < 1인 실패(aux 실패)는 구간에 넣지 않는다.
- **주 칸**: 주 판정기, k = 1, 6과제(t1, t2, t4, t5, t6, t8) 합침. t0은 따로 보고한다.
- **H1a**(셋 다 성립해야 한다)
  - (i) 실패(r ≥ 1)만으로 logit P(Ŝ=1) = α + β·log r을 맞춘다. 문구 그대로 과제 항 없이 합친다. β의 cluster-bootstrap 95% CI가 0 아래여야 한다.
  - (ii) near ≥ 0.3
  - (iii) near/far ≥ 3
  - (ii)·(iii)은 점 추정으로 판정하고 CI를 함께 낸다.
- **H1b**(셋 다 성립해야 한다)
  - ΔAUROC_near = AUROC_real − AUROC_imag,k=1(성공 vs near) ≥ 0.05
  - ΔAUROC_far(성공 vs far) ≤ 0.02
  - k ∈ {1, 2, 3, 4}에 대한 [AUROC_imag(k) − AUROC_real](성공 vs near)의 OLS 기울기. cluster-bootstrap 95% CI가 0 아래여야 한다.
  - 점수: (a) logit, (c) V, (d) P(Yes)
- **bootstrap**
  - cluster = 시작 상태(과제, 데모)
  - 2,000회, seed 0, percentile CI
- **곡선 요약**(보고)
  - 성공·실패 전체로 logit P(Ŝ=1) = α + β·log r를 실제와 상상에서 따로 맞춘다.
  - r₅₀, r₁₀, Δr₁₀ = r₁₀(상상) − r₁₀(실제)
  - 구간 곡선: r < 0.8, 폭 0.2 11칸, r ≥ 3. 각 칸에 CI를 붙인다.
- **민감도**(판정에 쓰지 않음)
  - 과제 절편을 넣은 모형
  - 시작 상태 무작위 절편 GLMM(가능하면)
  - 과제별, 다른 판정기·k
  - Holm 보수(98.3%) CI
- **지각 바닥**(판정기마다): 실제 프레임의 P(Ŝ=1)를 near, mid, far, 성공별로 낸다.
- **정보 상한(D3)**: 상상 프레임과 실제 프레임의 DINOv2 특징으로 로지스틱 회귀를 학습한다. 시작 상태 묶음 5-fold로 AUROC(성공 vs near / far)를 잰다.
- **go/no-go**: 주 칸에서 H1a 또는 H1b가 성립하면 go다.
