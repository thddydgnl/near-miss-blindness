### 공통
- 판정기는 모두 고정이다: M1은 E1의 (a) 앙상블(a_full, a_obj), DP는 a_std, 참고로 (b). M3는 R2-9 고정 판별기다. 실제 프레임 판정은 월드모델 변형과 무관하다(인코더 고정).
- 곡선 집합의 두 오판
  - NM(near-miss 오판) = P(상상 판정 성공 | 1 ≤ r < 2)
  - SM(성공 오판) = P(상상 판정 실패 | r < 1)
  - 칸의 반사실 기록(E1과 같은 행)에서 잰다.
- 학습 seed는 조건마다 3개다. 기록마다 seed 3개 판정의 평균을 쓴다(E1 M3와 같은 합치기).
- 짝 비교: 같은 기록, cluster bootstrap 10,000회(M1 곡선은 출처 궤적, DP는 episode, M3는 장면). "유의"는 차이의 95% 구간이 0을 넘지 않는 것이다. 단측 bootstrap p도 적는다.

### E4a 데이터 균형 인과 시험
- **M1 미세조정 자료**
  - 궤적: train 분할에서 E1의 J·C·T를 뺀 나머지 F(길이 ≥ 52, 12,584개)
  - 창: DINO-WM 학습 단위 그대로(프레임 4장, frameskip 5, 행동 20개). 시작 창 3,000개(seed 20261101)
  - 창마다 전문가 행동 + 교란 7개. 교란은 E1 판별기 집합과 같은 혼합이다: iid·offset·scale·gross, 크기 = C에서 정한 H3 50% 성공 크기 × log-U[0.3, 3].
  - 라벨: 15 step 뒤 원 정의 r(같은 창의 전문가 상태 대비). r < 1이면 목표 도달(성공).
  - **S97**: 표본 10,000개 = 성공 9,700 + 실패 300. **S50**: 5,000 + 5,000. 같은 풀에서 고정 seed로 뽑는다.
- **미세조정**
  - 공개 체크포인트에서 시작한다. predictor + proprio·action encoder를 학습하고, DINOv2와 decoder는 고정한다.
  - 손실은 DINO-WM 그대로다(시각 + proprio embedding MSE, 4프레임 teacher forcing).
  - AdamW, lr 1e-4(원 학습 5e-4의 1/5), warm-up 100 step 뒤 cosine, batch 32, **3,000 step**
  - seed 0·1·2(batch 순서와 dropout). 조건 사이에 다른 것은 자료 구성뿐이다.
- **평가**
  - 주 칸: E1 val H5 r, 판정기 (a) a_full 앙상블(H1 칸)
  - 보조: val H5 r_obj((a) a_obj), trainsplit H5 r
  - 세 칸을 같은 seed로 다시 생성해 원 모델·S97·S50으로 다시 상상한다.
- **H4a(M1)**: S97 − S50의 NM 차이 > 0이고 SM 차이 < 0이며, 둘 다 짝 95% 구간이 0을 넘지 않는다. 원 모델과의 차이도 보고한다.
- **H4a(M3)**: E1 자료로 판정한다. p = 0.03 − p = 0.3(가장 균형 잡힌 학습 수준)의 NM 차이 > 0과 SM 차이 < 0을 장면 bootstrap 짝 구간으로 본다. p = 0.1은 용량-반응 중간값으로 보고한다.
- H4a는 M1 또는 M3에서 성립하면 성립이다(설계 문구).

### E4b 정보가 사라지는 위치
- **H4b**(모델마다, 점추정 기준, 구간 보고)
  - 실제 프레임 정보 상한 = (a)의 실제 프레임 AUROC(성공 대 near)
  - 상상 = 상상 특징으로 학습한 상한 판별기(ai)의 상상 AUROC
  - 기준: 실제 ≥ 0.95이고 (실제 − 상상) ≥ 0.05
  - 주 칸은 M1 val H5 r(E1 자료). 상상 단계별 곡선은 H 3·5·7·10이다. M3는 p = 0.03이다(실제 프레임 판별기 vs 모델별 상한 판별기, E1 자료).
- **M3 해상도 sweep**(서술, 판정 없음; p = 0.03, seed 3개씩)
  - R1: 토큰 256 × PCA 64
  - R2: 토큰 64 × PCA 384
  - R3: 예측기 작게(d 64, 2층)
  - R4: 예측기 크게(d 256, 8층)
  - 토큰 256 × PCA 384는 bank가 seed당 약 38GB라 뺀다(E0 보고).
  - 표현이 바뀌는 R1·R2는 frame bank, 고정 판별기, E1 grid를 같은 방법으로 다시 만든다.
  - 지표: 실제 AUROC, 상상 AUROC(고정 판별기), 상상 상한 AUROC, NM, SM, r50

### E4c 손실 단계 coarsening (서술)
- M1: F 창의 실제 특징 혁신 Δz = z(t+5) − z(t) 에너지를 patch 마스크(T 블록, agent, 배경; 상태에서 14 × 14 격자로 계산)로 나눈 몫을 잰다. 원 DINO-WM 예측 오차 에너지의 같은 몫도 잰다. R2-11처럼 PCA 50으로 줄인 Δz에서 블록 자세 변화와 agent 변위의 고유 R²도 잰다.
- M3: 같은 것을 물체·그리퍼 토큰으로 잰다.
- **(v)의 가중 규칙**: 경계 관련 patch(M1은 T 블록, M3는 물체)의 가중 λ를, 기준 학습 자료에서 그 patch가 가중 혁신 에너지의 50%를 갖도록 정한다. 이미 50% 이상이면 λ = 1이다.

### E5 처방 (노출량 맞춤)
- **M1**(공개 체크포인트에서 미세조정, E4a와 같은 lr·step·batch·seed)
  - 모든 처방: S97의 성공 9,700개 + 고유 실패 창 정확히 300개, batch 32 중 실패 8개(25%)
  - (0) 기준: S97 그대로(E4a)
  - (i) 균일 재가중: S97의 실패 300개를 25%로
  - (ii) 경계 근처 반사실: 성공 창 300개에 E1 grid 방식(offset·iid 반씩, 14회 이분 탐색)으로 r* ~ U[1, 2)인 실패
  - (iii) 대비 쌍(보조): (ii)의 실패 + 같은 시작 창·같은 패턴의 짝 성공 r* ~ U[0.8, 1). batch는 실패 25% + 짝 성공 25% + 기본 성공 50%
  - (iv) CureWM식 전 범위: r* ~ U[1, 6]인 반사실 실패 300개
  - (v) 경계 가중 손실: (i)의 자료와 batch에 T 블록 patch 가중(λ, E4c)
- **M3**(처음부터 학습, T 6,000, batch 256, seed 0·1·2). 기본 자료 p = 0.03과 p = 0.1. 실패 수 = 그 seed 기본 자료의 실패 수, batch 안 실패 25%
  - (i) 기본 실패(r ~ U[1, 2)) 25%
  - (ii) 같은 실패 장면을 r ~ U[1, 1.2)로 다시 그림
  - (iii) (ii) + 짝 경계 성공 r ∈ [0.8, 1). 25% + 25% + 50%(R2-9 cp 구성)
  - (iv) 같은 실패 장면을 r ~ U[1, 3]으로 다시 그림
  - (v) (i) + 물체 토큰 가중(λ, E4c)
- **H5a**
  - 설정 3개: M1(val H5 r, (a)), M3 p = 0.03, M3 p = 0.1(E1 grid, 고정 판별기)
  - 한 설정에서 성립: NM(ii) < NM(i)이고 NM(ii) < NM(iv)이며, 각 짝 95% 구간이 0 아래다. 또한 SM(ii) − SM(0) ≤ 0.05(점추정)다.
  - H5a는 3개 중 2개 이상에서 성립하면 성립이다.
- **H5b**(M1만, DP 집합 H5, 원 모델, 재학습 없음)
  - MC dropout: 창마다 확률적 상상 K = 16번(predictor dropout 0.1만 켬, seed 고정). 표본마다 a_std로 판정하고, 성공 판정 표본의 비율 a를 잰다.
  - 할인 규칙: a ≥ q*일 때만 성공으로 판정한다.
  - q* ∈ {1/16, …, 16/16}은 개발 집합에서 정한다. 개발 집합은 a_std 학습용 rollout(24 checkpoint × 25 episode, seed 300000~300599, E2와 겹치지 않음)의 H5 창이고, 정책 24개의 평균 |o_π|를 최소로 하는 값을 고른다(동률이면 작은 값).
  - 보류 규칙(0 < a < 1인 창을 빼고 정책 비율을 냄)은 보조로 보고한다.
  - H5b 성립: E2 평가 집합에서 할인한 평균 |o_π|가 E2 기본 판정(dropout 끔)보다 작고 짝 episode bootstrap 95% 구간이 0 아래이며, FGRE도 작다(점추정). Pearson, MMRV, Spearman(n, o_imag)도 보고한다.
