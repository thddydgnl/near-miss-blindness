### E2 M1 (주 정책 집합: DP checkpoint 24개)
1. 정책 수준 양(checkpoint마다 100 episode, 초기 상태 seed 100000~100099를 모든 checkpoint가 공유)
   - s_π = P(r_obj < 1), n_π = P(1 ≤ r_obj < 2). 최종 상태, 고정 목표 (256, 256, π/4) 기준
   - ŝ_π = P(a_std 앙상블 확률 평균 ≥ 0.5), 마지막 5H 제어 step 창의 상상 최종 프레임
   - ŝ_π^real = 같은 판정기를 같은 창의 실제 최종 프레임에 적용한 값
   - o_π = ŝ_π − s_π, 상상 몫 o_π^imag = ŝ_π − ŝ_π^real, 판정기 몫 o_π^judge = ŝ_π^real − s_π
   - 주 칸 H = 5. H = 3·7·10은 보조
   - T_end < 5H인 episode: 앞에 0 행동을 채워 창을 5H로 맞춘다. 초기 상태의 속도가 0이라 시뮬레이터에서는 정확히 정지다. 그런 episode 수를 보고한다(판별기 학습 rollout 600개에서는 최소 T_end 61이라 없을 것으로 본다).
2. H2a: 24개에서 Spearman(n_π, o_π^imag) ≥ 0.6(점추정)
   - 95% 구간: episode cluster bootstrap 10,000회. 초기 상태가 checkpoint 사이에 짝이므로 100개 초기 상태를 함께 재표집한다.
   - Holm용 p: 정책 단위 순열 검정(단측, H0: ρ ≤ 0, 10,000회). bootstrap p(ρ* ≤ 0)도 함께 적는다.
3. H2b
   - (i) |s_i − s_j| ≤ 0.05이고 |ŝ_i − ŝ_j| ≥ 0.15인 쌍이 하나 이상(점추정)
   - (ii) "비슷한 성공률 집합 안의 Kendall τ"는 |s_i − s_j| ≤ 0.05인 쌍 전체에서 계산한 τ_b다. τ = (C − D) / √((C + D + T_s)(C + D + T_ŝ)). C·D는 일치·불일치 쌍, T_s·T_ŝ는 s에서만·ŝ에서만 같은 쌍이다. 둘 다 같은 쌍은 뺀다. 기준 τ ≤ 0.5
   - 민감도: 실제 성공률 폭 5%p 창 가운데 정책이 가장 많은 집합 안의 τ_b
4. H2c: Pearson(ŝ_π, s_π) ≥ 0.8이고 MMRV ≤ 0.05(점추정)
   - MMRV(SIMPLER) = (1/N) Σ_i max_j |s_i − s_j| · 1[(ŝ_i < ŝ_j) ≠ (s_i < s_j)]
5. 실패 기하 가중 순위 오류(FGRE, 제안 지표, 판정 문턱 없음)
   - FGRE = (1/N) Σ_i max_{j: |s_i − s_j| ≤ 0.05} |n_i − n_j| · 1[(ŝ_i < ŝ_j) ≠ (s_i < s_j)]
   - MMRV와 같은 mean-max 꼴이다. 비슷한 성공률 쌍으로 한정하고, 가중을 실제 성공률 차이 대신 near-miss 비중 차이로 준다.
6. 통제(R2-12 main 집합, val, H5, 400 episode, seed 303, 교란 정책 8개): 판정기 a_full 앙상블과 (b) τ_full, 원 정의 r(s = P(r < 1), n = P(1 ≤ r < 2)). 같은 통계를 출처 궤적 cluster bootstrap 10,000회로 따로 보고한다. H2 판정에는 넣지 않는다.

### E2 M3
- R2-9 정책 π1~π6 × 시작 장면 1,024(R2-9 평가 bank, seed 12345) × E1 모델 9개
- p마다 seed 3개를 합친다(ŝ_π = 모델 3개 판정의 평균). s_π, n_π는 실제 r로 정한다(모델과 무관).
- n_π 주 구간 [1, 1.2)(v2 §5), 설계 구간 [1, 2)를 함께 보고한다. 실제 프레임 판정(지각)은 고정 R2-9 판별기를 실제 f4에 적용한 값이다.
- 주 칸 p = 0.03. 통계는 M1과 같다. bootstrap은 장면 1,024개를 정책·seed에 공통으로 재표집한다(10,000회).

### E3 (M1; M3 몫은 E1·E2 자료로)
- 판정기 × 입력 2×2: (a)(E1 곡선 집합은 a_full·a_obj, DP는 a_std), (b)(dset 목표 집합만), (d) × {실제, 상상} 최종 프레임
- near-miss 오판 = P(Ŝ = 1 | near). 상상 몫 = (P_상상 − P_실제) / P_상상
- H3의 주 칸(제안): H1과 같은 칸(M1: val, H5, r, (a) 앙상블; M3: p = 0.03 합침). 다른 칸((b), (d), r_obj, 다른 H, DP a_std)은 모두 보고한다.
  - 주의: M1 (a)의 이 칸 값은 E1에서 이미 나왔다(0.112 → 0.147).
  - 대안은 DP 집합(a_std, H5)을 주 칸으로 하는 것이다. 이 값은 아직 계산하지 않았다.
- (d) 절차(평가 집합에 VLM을 돌리기 전에 고정)
  - 모델: Qwen/Qwen2.5-VL-7B-Instruct(M2와 같음), bf16, transformers 4.57.1(M2와 같음)
    - flash-attn 대신 SDPA를 쓴다(서버 드라이버·torch에 맞는 wheel이 없음).
    - GPU 1을 A와 나눠 쓰므로 가중치 일부를 CPU에 둔다(GPU 예산 약 11GiB). 수치는 bf16 그대로다.
  - 점수: 다음 토큰 logit을 {Yes, No}로 제한한 P(Yes)(M2와 같음)
  - 입력: 목표 프레임과 최종 프레임 두 장. 실제와 상상 모두 DINOv2 특징을 VQ-VAE decoder로 되돌린 224 px 이미지다(실제 프레임도 encode → decode).
  - 프롬프트 3종(고정)
    - dset 목표·원 정의 r: T 블록과 파란 원의 위치·자세가 목표와 같은지
    - dset 목표·r_obj: T 블록의 위치·자세만
    - DP 표준 목표: 연두색 목표 T 위에 블록이 같은 자세로 놓였는지
  - 규칙 집합(평가 집합과 겹치지 않음)
    - dset 목표: E1 판별기 학습 집합(J 궤적)의 held-out episode 20%(413 episode, 3,304 궤적)로 held AUROC를 잰다. 같은 집합의 학습 부분에서 seed로 뽑은 2,000개로 Yes 문턱(균형 정확도 최대)을 정한다.
    - DP 표준 목표: a_std 학습 프레임의 held-out(2,398장)과 학습 부분 2,000장으로 같은 방식
  - 기준(v2.1): 실제 프레임 held AUROC(성공 대 실패) ≥ 0.80이면 판정기, 아니면 보조. (dset·r), (dset·r_obj), (DP·r_obj) 셋을 따로 판정한다.
  - 평가 범위(처리량에 따라 이 순서로)
    1. E1 val H5의 r·r_obj 칸, DP H5 창
    2. E1 val r의 H3·7·10, DP의 H3·7·10
    3. E1 val r_obj의 H3·7·10
    - trainsplit은 (d)를 돌리지 않는다.
