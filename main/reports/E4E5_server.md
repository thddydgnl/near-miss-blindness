## 1. 무엇을 돌렸나

### 1.1 공통 (v3.1 §9)

- 두 오판은 칸의 반사실 기록(E1과 같은 행, 구간은 칸의 정의)에서 잰다.
  - NM(near-miss 오판) = P(상상 성공 판정 | 1 ≤ r < 2)
  - SM(성공 오판) = P(상상 실패 판정 | r < 1)
- 판정기는 모두 E1에 고정한 것이다: M1은 (a) 앙상블(a_full, a_obj)과 DP의 a_std, M3는 R2-9 판별기다. 실제 프레임 판정은 월드모델과 무관하다.
- 학습 seed는 조건마다 3개다. 기록마다 seed 3개 판정의 평균을 쓴다.
- 짝 비교는 같은 기록에서 cluster bootstrap 10,000회로 한다(M1 곡선은 출처 궤적, DP는 episode, M3는 장면). "유의"는 차이의 95% 구간이 0을 넘지 않는 것이다.

### 1.2 M1 미세조정 자료 (`e4_m1_ftdata.py`)

- 궤적: train 분할에서 E1의 J·C·T를 뺀 F(12,584개). 평가 집합(val, T)과 판별기 학습 집합(J)과 겹치지 않는다.
- 창: DINO-WM 학습 단위 그대로(프레임 4장, frameskip 5, 행동 20개) 3,000개
- 변형: 창마다 전문가 + 교란 7개(E1 판별기 집합과 같은 혼합, C에서 정한 H3 크기 × log-U[0.3, 3])
- 라벨: 15 step 뒤의 원 정의 r(같은 창의 전문가 상태 대비). 풀 24,000개 중 성공 54%, near 18%, mid 9%, far 19%
- **S97** = 성공 9,700 + 실패 300(실패의 구간: near 36%, mid 19%, far 45%), **S50** = 성공 5,000 + 실패 5,000. S50의 성공은 S97 성공의 부분집합이고, S97의 실패는 S50 실패의 부분집합이다.
- E5 반사실(E1 grid 방식, 창마다 패턴 하나, 14회 이분 탐색)
  - (ii) 경계 근처 실패 300개: r* ~ U[1, 2), 달성 [1.002, 1.998]
  - (iii) 같은 창·같은 패턴의 짝 성공 300개: r* ~ U[0.8, 1), 달성 [0.800, 0.999]
  - (iv) 전 범위 실패 300개: r* ~ U[1, 6], 달성 [1.013, 5.96]
- 렌더한 15,600개 행동열의 DINOv2 특징(fp16, 7.0GB)과 정규화한 proprio·행동, T 블록·agent patch 마스크를 저장했다.

### 1.3 M1 미세조정 (`e4_m1_finetune.py`)

- 공개 체크포인트에서 시작한다. predictor + proprio·action encoder를 학습하고, DINOv2와 decoder는 고정한다.
- 손실: DINO-WM 그대로(시각 + proprio embedding MSE, 프레임 0~2에서 1~3을 teacher forcing)
- AdamW lr 1e-4(원 학습의 1/5), warm-up 100 step 뒤 cosine, batch 32, 3,000 step, seed 0·1·2
- 학습 모드의 dropout(attention 포함, 0.1)을 원 구현과 같게 켠다.
- 실행 세부: forward를 bf16 autocast로 했다(fp32 가중치; 04:13Z, 결과 전 결정). 실행 하나에 약 21분이다.
- 조건(실행 21개): E4a S97·S50, E5 (i) rw·(ii) near·(iii) cp·(iv) full·(v) bw, 각 seed 3개
  - E5는 모두 S97의 성공 9,700개 + 고유 실패 300개, batch 32 중 실패 8개(25%)다. (iii)은 실패 8 + 짝 8 + 기본 성공 16이다.
  - (v)의 λ_block = 4.30(E4c 규칙)
- 평가(`e4_m1_eval.py`)
  - E1의 val H5 r(주 칸), val H5 r_obj, trainsplit H5 r 칸을 같은 seed로 다시 생성했다(달성 r이 E1과 정확히 같음).
  - 원 모델과 21개 변형으로 다시 상상해 (a) 앙상블과 d_vis로 판정했다.

### 1.4 M3 (`m3/`)

- E4a: E1의 p = 0.03 / 0.1 / 0.3 모델(seed 3개씩)과 E1 grid 기록을 그대로 쓴다(새 학습 없음).
- E5 처방(`m3_e5_data.py`, `wm_e5.py`): 기본 자료 p = 0.03과 p = 0.1, 처음부터 학습(T 6,000, batch 256, seed 0·1·2)
  - 실패 장면과 실패 수는 기본 자료 그대로다(p = 0.03: 916 / 895 / 888, p = 0.1: 3,018 / 2,945 / 2,995). 실패 episode의 정렬 오차만 바꾼다.
    - (i) rw: 기본 실패 U[1, 2)
    - (ii) near: 같은 장면을 r = 1 + 0.2 v2(R2-9 near-miss 규칙, [1, 1.2))로 다시 그림
    - (iii) cp: (ii) + 짝 경계 성공 r = 0.8 + 0.2 v3, 25% / 25% / 50%(R2-9 cp 구성)
    - (iv) full: 같은 장면을 r ~ U[1, 3]으로 다시 그림
    - (v) bw: (i) + 물체 토큰 가중(λ_obj = 5.04)
  - batch 안 실패는 25%(256개 중 64개)다. 초기화·표집 seed는 R2-9와 같다.
  - 평가: E1 grid(49 × 128)와 R2-9 정책 bank를 고정 판별기로 본다(`m3_e5_eval.py`). 기준 (0)은 E1의 std 모델이다.
- E4b 해상도 sweep(`sweep.py`, p = 0.03, seed 3개씩)
  - R1: 토큰 256 × PCA 64
  - R2: 토큰 64 × PCA 384
  - R3: 예측기 d 64 / 2층
  - R4: 예측기 d 256 / 8층
  - R1·R2는 frame bank, 판별기, E1 grid를 같은 장면 draw로 다시 만들었다.

### 1.5 H5b (`e5_h5b_mcdrop.py`)

- 공개 모델의 predictor dropout(0.1)을 켜고 창마다 K = 16번 상상해, 표본마다 a_std로 판정했다. a = 성공 판정 표본의 비율이다.
- q*는 개발 집합(a_std 학습용 rollout 600개, seed 300000~300599)의 정책 24개에서 평균 |o_π|를 최소로 하는 k/16이다.
- E2 평가 집합(H5, 2,400창)에 a ≥ q* 규칙을 적용하고, E2의 기본 판정(dropout 끔)과 비교했다.

- DINOv2 patch 특징은 맥락을 섞는다. 그래서 물체가 없는 배경 patch도 프레임 사이에 변하고, 그 변화가 손실의 70% 이상을 차지한다. 경계를 정하는 변수(T 블록 자세, 물체 위치)가 손실에서 차지하는 몫은 17~22%다.
- R2-11식 고유 R²(M1, PCA-50 Δz): 블록 자세 변화 0.021, agent 변위 0.026(합 0.060). 선형으로 읽히는 상태 변화의 몫 자체가 작다.
- 경계 가중 λ(규칙: 경계 patch가 가중 혁신 에너지의 50%): M1 λ_block = 4.30, M3 λ_obj = 5.04. 이 손실(E5 (v))의 효과는 3장에 있다.

## 5. 편차와 결정이 필요한 것

### 5.1 편차·사고(모두 기록, 결과에 영향 없음)

1. **M1 미세조정의 bf16 autocast**(04:13Z, 결과 전): fp32/TF32로는 0.61초/step이라 21개 실행이 공유 GPU에서 너무 길었다. forward만 bf16으로 했다(fp32 가중치·optimizer, 모든 조건 같음). 첫 두 실행(fp32)은 저장 전에 멈췄다.
2. **lane 재시작 중 `pkill -f` 사고**(05:21Z): 자기 ssh 명령까지 맞춰 끊었다. 학습 중이던 M3 모델 하나(p = 0.1 near s0)를 잃어 다시 학습했다. seed가 같아 결과는 같다.

### 5.2 결정이 필요한 것

1. **H4a의 서술 범위**: 성립은 M3(처음부터 학습한 통제 모델)에서만 나왔다.
   - 공개 DINO-WM의 짧은 미세조정에서는 성공 오판 감소만 유의했고, near-miss 오판 증가는 원 정의에서 나타나지 않았다(r_obj 보조 칸에서는 나타남).
   - "성공 편중 데이터가 낙관을 만든다"를 통제 모델의 인과 결과로 쓰고, 공개 모델에서는 부분적이라고 쓸지 정해야 한다.
2. **H5a 부정 결과**: 노출량을 맞추면 경계 근처 반사실이 재가중보다 낫지 않다(M3에서는 유의하게 나쁨). R2-9의 "cp·nm 효과는 실패를 경계에 둔 데서 온다"는 해석은 노출량을 맞춘 비교에서 지지되지 않는다. 처방 부분의 주장을 어떻게 줄일지 정해야 한다.
3. **H5b의 크기**: 규칙상 성립이지만 평균 |o_π| 감소는 0.005다(E2의 편향 자체가 작음). "평가 쪽 할인이 near-miss 법칙(Spearman 0.36 → 0.02)과 FGRE를 줄인다" 정도로 쓸지 정해야 한다.
4. M3 sweep의 예측기 용량 효과(NM 1.000 → 0.535 → 0.149)는 사전등록 가설 밖의 강한 서술 결과다. 논문의 "정보가 사라지는 위치" 절에 넣을지 정해야 한다.
