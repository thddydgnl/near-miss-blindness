### 0.2 M1 (공개 DINO-WM PushT; 상세는 E0_server.md 8장)
- **실패 거리**
  - dset 목표 집합(E1 반사실, R2-12 교란 정책)
    - 원 정의 r = max(‖Δ(agent, block) xy‖₂ / 20 px, |Δθ| / (π/9)), 평가기 `eval_state`와 같다.
    - 물체 자세만 r_obj = max(‖Δblock xy‖₂ / 20 px, |Δθ| / (π/9))
  - DP episode(표준 PushT, 목표 (256, 256, π/4)): r_obj만 정의된다.
  - 성분(agent·block·각도)을 궤적마다 기록하고, near-miss를 지배 성분별로 보고한다.
  - 곡선은 달성된 r로 그린다.
- **구간**: 성공 r < 1, near 1 ≤ r < 2, mid 2 ≤ r < 3, far r ≥ 3. 주 분석은 연속 곡선이다.
- **판정기**
  - (a)는 R2-12 구조로, 정의마다 따로 학습한다: a_full, a_obj, a_std.
    - **K = 5 seed 앙상블**(확률 평균 ≥ 0.5)이 판정기의 정의다. 구성원 간 표준편차를 함께 보고한다.
    - 사용 조건은 실제 프레임 held-out 정확도 ≥ 0.95다. E0 값: a_full 0.953~0.958, a_obj 0.962, a_std 0.975
  - (b)는 d_vis 문턱이다(τ_full = 0.2125, τ_obj = 0.345). dset 목표 집합에만 쓴다.
  - (d)는 VQ-VAE decoder로 실제와 상상을 모두 encode → decode한 뒤 VLM에 보인다.
  - 지각 바닥을 먼저 보고한다. 모든 문턱은 평가 집합을 상상하기 전에 고정한다.
- **정책 집합**
  - **주 분석: Diffusion Policy 24개.** 저차원 CNN U-Net, 표준 PushT 시연, seed 42·43·44 × epoch 20·25·30·40·50·80·220·1000, EMA 가중치다.
  - **통제 대비: R2-12 교란 정책 8개.** 따로 보고한다. 정책 24개일 때 검정력은 약 0.89다(설계 6.7절의 32개 기준 0.95를 정정).
- **반사실 severity grid**
  - H ∈ {3, 5, 7, 10} × 정의 ∈ {r, r_obj}마다 r*를 [0.8, 3]에 층화 균등으로 3,000개 둔다.
  - 꼬리로 [0.2, 0.8)과 [3, 6]에 각 300개를 더한다.
  - 표적마다 severity를 이분 탐색(14회)으로 정한다. 패턴은 offset과 iid를 반씩 쓴다.
  - 보정 sweep은 판별기에 쓰지 않은 train 분할에서 한다.
- **episode와 분할**
  - DP 평가 seed 100000~(checkpoint 사이 짝 초기 상태), 단계 선택 200000~, 판별기 학습 300000~, E0 시연 900000~
  - dset 평가는 val 21궤적이다. 보조 집합으로 R2-12 trainsplit을 둔다.
  - bootstrap 단위: dset은 출처 궤적, DP는 episode다.
- **행동 변환**: a_t = (A_t − agent_t)/100(DINO-WM 정규화 후 5 step씩)
- **DP 모드 O**: 마지막 5H 제어 step 창. 참값은 최종 r_obj, 판정은 a_std 앙상블이다. 같은 창의 실제 최종 프레임 판정으로 지각 바닥과 상상 몫을 나눈다.

## 1. 연구 질문과 가설 (설계 3장 그대로)


| RQ | 질문 | 가설(사전등록) |
|---|---|---|
| RQ1 곡선 | 상상이 실패를 성공으로 판정할 확률은 실패 거리 r과 어떤 관계인가? | H1a: 모델마다 P(Ŝ = 1 \| 실제 실패, r)가 r에 대해 단조 감소한다. near-miss 구간(1 ≤ r < 2)이 far-miss(r ≥ 3)의 3배 이상이고 0.3 이상인 모델이 3개 중 2개 이상이다. H1b: 성공 vs near-miss AUROC는 상상에서 실제 프레임보다 0.05 이상 낮다. 성공 vs far-miss AUROC의 하락은 0.02 이하다(near-miss 특이적 손실). 이 차이는 상상 길이와 함께 커진다 |
| RQ2 정책 법칙 | 정책 평가의 편향은 실패의 기하를 따르는가? | H2a: 학습된 정책 checkpoint 집합에서 상상이 만든 과대 추정 o_π^imag가 near-miss 비중 n_π와 Spearman 0.6 이상이다(모델 2개 이상). H2b: 실제 성공률 차이 ≤ 5%p인 정책 쌍에서 상상 성공률 차이가 15%p 이상인 쌍이 하나 이상 있다. 그런 정책 집합 안의 Kendall τ(상상 대 실제)는 0.5 이하다. H2c: 같은 조건에서 전체 정책 Pearson은 0.8 이상이고 MMRV는 0.05 이하로 "좋게" 보인다(표준 지표의 맹점) |
| RQ3 원천 | 오판은 판정기 때문인가 상상 때문인가? | H3: 2×2(판정기 × 실제 / 상상 프레임) 분해에서 near-miss 오판의 과반이 상상 몫이다(모델 2개 이상). VLM 판정기는 실제 프레임에서도 자체 낙관을 더한다(보고) |
| RQ4 기전 | 무엇이 양방향 흐림을 낙관으로 바꾸나? 정보는 어디서 사라지나? | H4a(인과): 같은 월드모델을 성공 편중 데이터로 미세조정하면 near-miss의 상상 성공이 늘고, 실제 성공의 상상 실패는 준다. 실패율 p에 대한 용량-반응이 있다. H4b(위치): 실제 프레임 특징에는 near-miss 정보가 남아 있다(정보 상한 AUROC ≥ 0.95). 상상 특징에서 사라진다(R2-12 D3 재현) |
| RQ5 처방 | 무엇이 경계를 되살리나? | H5a(데이터): 실패 노출량을 맞추면 경계 근처 반사실(near-miss 위주 severity grid) 증강이 재가중과 CureWM식 전 범위 반사실보다 near-miss 오판을 더 줄인다(설정 2개 이상). 성공 오판 증가는 5%p 이하다. H5b(평가 쪽, 재학습 없음): 상상 불확실성(앙상블 / MC dropout)으로 경계 근처 상상 성공을 할인하거나 보류하면 정책 수준 편향과 순위 오류가 준다 |
| RQ6 결과 | 이 편향이 checkpoint 선택을 얼마나 망치나? | H6: 월드모델 점수로 고른 checkpoint의 regret(실제 최선 대비)이 near-miss 비중이 높은 checkpoint에서 생긴다. 처방은 regret을 줄인다 |

## 2. 방법 (설계 4장 그대로)


### 4.1 정의
- **실패 거리 r**: 과제마다 미리 정한 연속 오차 e를 그 과제의 성공 문턱 τ로 나눈 값이다(r = e / τ).
  - 성공은 r < 1이다.
  - 과제별 e의 정의는 사전등록한다.
    - PushT: 평가기의 위치·자세 오차. agent 위치를 포함한 원 정의와 물체 자세만의 정의 두 가지
    - LIBERO: 물체와 목표 영역 경계의 거리, 또는 관절 각 문턱까지의 거리
    - 통제 장면: 정렬 오차 / 반폭
- **구간(보조)**: 성공 r < 1, near-miss 1 ≤ r < 2, mid 2 ≤ r < 3, far-miss r ≥ 3(R2-12와 같음)
  - 주 분석은 구간이 아니라 연속 곡선이다(4.3절).
  - R2-9의 정렬비 [1, 1.2)는 통제 장면 보조 구간으로 함께 보고한다.
- **상상 판정 Ŝ**: 같은 초기 관측과 같은 행동열(또는 같은 정책)로 월드모델을 굴린 뒤, 예측 최종 관측을 판정기 j로 판정한다.
- **판정기 j**(모델마다 해당하는 것)
  - (a) **oracle 판별기**: 실제 최종 프레임의 특징 + 목표로 학습한 작은 분류기. 실제 프레임 정확도 0.95 이상을 요구한다(R2-12 (a)).
  - (b) 목표 latent 거리 문턱(DINO-WM 계획 비용의 시각 항)
  - (c) 월드모델 자체의 value head(Cosmos Policy)
  - (d) VLM 판정기(공개 VLM, 고정 프롬프트, 목표 문장 포함)
- **평가 모드**
  - **O(open-loop 재생, 주 분석)**: 실제 환경에서 실행한 정책의 행동열을 상상으로 재생한다. 정책과 월드모델의 상호작용을 배제하고 결과 예측만 본다.
  - **C(closed-loop 상상, 보조)**: 정책이 상상된 관측을 보고 행동한다. 실제 정책 평가 절차이며, LIBERO에서만 쓴다.

| M3 | 통제 모델: DINO-WM식 latent 예측기(R2-9) | 2D 집어 들기 렌더 장면, 학습 데이터 실패율 p ∈ {0.3, 0.1, 0.03} | 결정론적 시뮬레이터 | 데이터 균형의 인과 조작(RQ4), 처방(RQ5) |
| (선택) M4 | Ctrl-World(코드 github.com/Robert-gyj/Ctrl-World. 공개 체크포인트와 학습 데이터는 프로젝트 페이지에서 확인되지 않음) | 체크포인트의 학습 도메인에 맞춤 | 시뮬레이터 도메인이면 시뮬레이터, 아니면 없음 | 체크포인트를 E0 안에 돌릴 수 있으면 순위 실험만 보조로 넣음 |

- 실행 장소: M1·M3은 대학 GPU 서버, M2와 M4는 RunPod다(6.0절).

### 4.3 지표
- **실패 거리 곡선**
  - P(Ŝ = 1 | r)를 r의 로그에 대한 로지스틱(모델 × 판정기 × horizon 상호작용)으로 맞춘다.
  - 요약값
    - r₅₀: 상상 성공 확률이 0.5로 떨어지는 실패 거리
    - 흐림 폭 Δr₁₀ = r₁₀(상상) − r₁₀(실제 프레임): 상상이 경계를 얼마나 바깥으로 밀어내는가
  - 구간 확률(near / mid / far)을 함께 보고한다.
- **경계 해상도**
  - AUROC(성공 대 near-miss)와 AUROC(성공 대 far-miss)를 실제 / 상상 특징에서 잰다.
  - 정보 상한: 상상 특징으로 직접 학습한 판별기의 AUROC(R2-12 D3)
- **정책 수준 지표**
  - 실제 성공률 s_π
  - 상상 성공률 ŝ_π
  - 과대 추정 o_π = ŝ_π − s_π와 그 분해: 상상 몫 o_π^imag = ŝ_π − ŝ_π^real-judge, 판정기 몫 = ŝ_π^real-judge − s_π
  - near-miss 비중 n_π
- **순위 지표**
  - Spearman, Kendall τ(전체, 그리고 실제 성공률이 5%p 이내인 정책 집합 안)
  - Pearson, MMRV(SIMPLER 정의)
  - 제안 지표: **실패 기하 가중 순위 오류**. 실제 성공률이 비슷한 쌍의 순위 위반에, 두 정책의 near-miss 비중 차이로 가중을 준다. 정의는 사전등록한다.
- **checkpoint 선택 regret**: 월드모델 점수 1위 checkpoint의 실제 성공률과 실제 최선 checkpoint의 실제 성공률의 차이

  - 같은 모델의 모든 조건(판정기, horizon, 처방)
  - 같은 정책의 실제 rollout과 상상 rollout

**정책 집합**
- **M1(PushT)**

- **M2(LIBERO)**
  - 선정 과제마다 행동복제 정책(작은 Diffusion Policy)을 학습해 4개 단계 checkpoint를 둔다.
  - 공개 강한 정책(openpi π0.5 LIBERO, OpenVLA-OFT)을 기준점으로 함께 둔다.
  - 보조로 R2-12식 교란 계열(지속 offset → near-miss, iid → far-miss)을 같은 성공률로 보정해 둔다.

**반사실 실패 생성(곡선용)**
- 성공 궤적의 행동에 severity grid 교란을 더한 반사실을 시뮬레이터로 실행해 r을 얻는다(CureWM 방식).
- 단, grid를 경계 근처에 촘촘하게 둔다.
  - severity를 r ∈ [0.8, 3]에 균등하게 맞추도록 보정 sweep으로 정한다.
  - 모델당 near-miss 궤적을 1,000개 이상 확보한다.

**분할**
- 판정기 학습 데이터, 보정 데이터, 평가 데이터의 시작 상태가 겹치지 않게 한다.
- 월드모델 학습 분할과의 겹침도 기록한다. R2-12의 train 분할 점검을 이어받는다.

**episode 수**
- 곡선: 모델 × 판정기마다 궤적 3,000개 이상
- 정책 평가: checkpoint당 과제마다 100 episode(PushT) / 50 episode(LIBERO 과제당)

**판정기 기준**
- oracle 판별기는 실제 프레임 held-out 정확도 0.95 이상을 요구한다. 못 미치면 판정에 쓰지 않는다.
- 판정기마다 "지각 바닥", 즉 실제 프레임에서의 near-miss 오판을 먼저 보고한다(R2-12 지각 단서 규칙).

### 6.1 실험 1 — 실패 거리 곡선 (RQ1)
- **대상**: M1(H ∈ {3, 5, 7, 10}), M2(행동 청크 1~4개 상상), M3(p ∈ {0.3, 0.1, 0.03})
- **측정**: P(Ŝ = 1 | r) 곡선, r₅₀, 흐림 폭 Δr₁₀, 구간 확률, 경계 해상도 AUROC(실제 / 상상 / 상상 특징 학습 판별기)
- **판정(H1)**
  - H1a: 모델 3개 중 2개 이상에서 near ≥ 0.3이고 near / far ≥ 3이다. 판정기 (a) 기준을 우선하고 (c)와 (d)를 함께 보고한다.
  - H1b: 같은 2개 이상에서 Δ AUROC(성공 vs near) ≥ 0.05이고 Δ AUROC(성공 vs far) ≤ 0.02다. horizon 기울기 95% CI가 음수다.
- **go/no-go(E1의 M2 결과로 판단)**
  - M2에서 H1a 또는 H1b가 성립하면 go다.
  - M2에서 둘 다 실패하면 주장을 "latent 월드모델(M1·M3)의 경계 해상도"로 좁히고, 워크숍이나 RA-L 경로로 바꾼다.

### 6.2 실험 2 — 정책 수준 법칙과 순위 역전 (RQ2)
- **대상**: M1 checkpoint 24개와 교란 정책 8개, M2 checkpoint와 기준 정책, M3 정책 6개
- **측정**
  - o_π와 그 분해(상상 몫 / 판정기 몫), n_π
  - 순위 지표 전체(4.3절)
  - 모드 O를 주로 쓰고, M2는 모드 C도 함께 잰다.
- **분석**
  - o_π^imag ~ n_π 회귀. 정책 수준 cluster bootstrap(episode 재표집)을 쓴다.
  - 실제 성공률 5%p 이내 쌍의 상상 차이 분포
  - 표준 지표(Pearson, MMRV)와 제안 지표의 비교
- **판정(H2)**
  - H2a: Spearman(n_π, o_π^imag) ≥ 0.6(모델 2개 이상)
  - H2b: 조건을 만족하는 쌍이 하나 이상 있다. 비슷한 성공률 집합 안의 Kendall τ ≤ 0.5다.
  - H2c: 같은 모델에서 전체 Pearson ≥ 0.8이고 MMRV ≤ 0.05다.

### 6.3 실험 3 — 원천 분해 (RQ3)
- **2×2(또는 4×2)**: 판정기 {(a) oracle, (c) value head, (d) VLM, (b) latent 거리} × 입력 {실제 최종 프레임, 상상 최종 프레임}
- **보고**
  - near-miss 오판을 지각 바닥(실제 프레임)과 상상 증분으로 나눈다.
  - FailBench 결과(VLM의 성공 쪽 편향)와 연결한다.
- **판정(H3)**: 상상 증분이 near-miss 오판의 50%를 넘는 모델이 2개 이상이다.

### 6.4 실험 4 — 기전 (RQ4)
- **4a 데이터 균형의 인과 시험**
  - M1(DINO-WM PushT)을 성공 편중 데이터(목표 도달 구간 97%)와 균형 데이터로 같은 step만큼 짧게 미세조정한다. R2-12 다음 단계 2를 잇는다.
  - M3는 p를 바꿔 처음부터 학습한다.
  - 같은 정책 집합에서 "양방향 흐림"이 "낙관"으로 바뀌는지, 그리고 p에 대한 용량-반응을 본다.
- **4b 정보가 사라지는 위치**
  - 실제 프레임 특징의 정보 상한을 잰다(near-miss 판별 AUROC).
  - 상상 단계별 AUROC 감소를 잰다.
  - 예측기 표현의 해상도를 sweep한다(토큰 64 / 256, PCA 64 / 384, 예측기 크기). R2-9 다음 단계 3이다.
- **4c 손실 단계 coarsening(R2-11 연결)**
  - 학습 손실에서 경계 관련 변수(물체 자세, 접촉)가 차지하는 분산 몫을 잰다.
  - 그 몫을 키우는 **경계 가중 손실**(물체·접촉 근처 patch 가중)을 처방 후보로 넘긴다.
- **판정(H4)**
  - H4a: 성공 편중 미세조정에서 near-miss 상상 성공 증가와 실제 성공 상상 실패 감소가 모두 짝 CI로 유의하다(M1 또는 M3).
  - H4b: 실제 프레임 정보 상한 ≥ 0.95이고, 상상에서 0.05 이상 떨어진다.

### 6.5 실험 5 — 처방 (RQ5)
- **데이터 쪽(노출량 맞춤)**: 같은 실패 수와 같은 batch 내 실패 비율로 비교한다. R2-9가 노출량을 맞추지 못한 한계를 고친다.
  - (i) 균일 재가중
  - (ii) near-miss 반사실 증강(경계 근처 severity grid)
  - (iii) 대비 쌍(같은 시작 상태에서 경계 양쪽 행동)
  - (iv) CureWM식 반사실(severity 전 범위, 주 기준선)
  - (v) 경계 가중 손실(4c)
- **평가 쪽(재학습 없음)**
  - 앙상블 또는 MC dropout(DINO-WM 예측기 dropout 0.1)의 상상 불확실성으로 경계 근처 상상 성공에 할인을 준다. 또는 판정을 보류한다.
  - 실제 실행 중 실패 신호를 읽는 FARM류 readout을 상상에 적용한 기준선을 둔다.
- **판정(H5)**
  - H5a: (ii)가 (i)과 (iv)보다 near-miss 오판을 더 줄인다(설정 2개 이상, 짝 CI). 성공 오판 증가는 5%p 이하다. (iii)은 R2-9에서 짝 자체의 효과가 없었으므로(cp ≈ nm) 보조로 보고한다.
  - H5b: 평가 쪽 처방이 정책 수준 |o_π| 평균과 실패 기하 가중 순위 오류를 줄인다(M1·M2 중 1개 이상).

### 6.6 실험 6 — checkpoint 선택의 결과 (RQ6)
- M1 checkpoint 24개와 M2 checkpoint로 "월드모델 점수 1위 고르기"를 시뮬레이션한다.
- regret, 고른 checkpoint의 near-miss 비중, 처방 전후를 비교한다.
- **선택**: 월드모델 안에서 정책을 개선하는 작은 루프(PushT, reward = 상상 성공)를 돌려, 정책이 near-miss 쪽으로 수렴하는지(reward hacking) 본다.
- **판정(H6)**: 처방 없는 선택의 regret이 0보다 유의하게 크다. 처방이 그것을 줄인다(짝 bootstrap).

### 6.7 통계와 사전등록
- **곡선**
  - 로지스틱 GLMM(시작 상태 무작위 효과)으로 맞춘다.
  - r₅₀와 Δr₁₀의 CI는 시작 상태 cluster bootstrap으로 낸다.
- **정책 수준**: episode cluster bootstrap(10,000회) 95% CI
- **다중 비교**
  - 1차 가설군(H1a, H1b, H2a)에 Holm 보정을 한다.
  - 나머지는 탐색으로 표시한다.
- **검정력**
  - near-miss 궤적 1,000개면 P(Ŝ \| near) ≈ 0.38의 95% 구간 반폭은 독립 가정에서 약 ±0.03이다.
  - 시작 상태 cluster 때문에 실제 구간은 더 넓다. R2-12는 val 궤적 21개에서 시작해 [0.326, 0.431]이었다. 본 실험의 학습된 정책은 시뮬레이터의 무작위 시작 상태에서 돌리므로 시작 상태 수를 episode 수만큼 늘릴 수 있다.
  - 정책 법칙은 정책 수가 검정력을 정한다(M1 32개). 참 ρ = 0.6이면 정책 32개로 ρ = 0을 α = 0.05에서 기각할 검정력은 약 0.95다(Fisher z 근사).
- **사전등록 문서**: 실험 1 본 실행 전에 `DESIGN_main.md`로 고정한다. 과제별 e와 τ 정의, 판정기 선택 규칙, 정책 집합, seed 범위, 처방의 노출량 정의를 적는다.
- **보고 원칙**
  - 지각 바닥을 항상 함께 보고한다.
  - 판정기별 결과를 숨기지 않는다.
  - 판정 실패도 모두 보고한다.

## 7. v2.2 덧붙임 (2026-10-21T23:49Z, 조정자; E2·E3 분석과 평가 집합 VLM 판정 전)
- **FGRE(실패 기하 가중 순위 오류)**
  - FGRE = (1/N) Σ_i max_{j: |s_i − s_j| ≤ 0.05} |n_i − n_j| · 1[(ŝ_i < ŝ_j) ≠ (s_i < s_j)]
  - 문턱 없이 MMRV와 나란히 보고한다.
- **H2b의 Kendall τ**
  - |s_i − s_j| ≤ 0.05인 쌍 전체에서 τ_b를 계산하고, 기준은 τ ≤ 0.5다.
  - 민감도로 5%p 폭 창 가운데 정책이 가장 많은 집합의 τ_b도 보고한다.
- **M1 H2 주 칸**
  - DP 24개, H = 5, a_std 앙상블, n_π = P(1 ≤ r_obj < 2)
  - o_π^imag = ŝ − ŝ^real(같은 창의 실제 최종 프레임 판정)
  - bootstrap은 공유 초기 상태 100개를 재표집한다(10,000회). H2a의 p는 정책 단위 순열 검정(단측)이다.
  - T_end < 5H이면 앞을 0 행동으로 채운다.
- **M1 통제**: R2-12 main 8정책, a_full 앙상블과 (b), 원 정의 r. 따로 보고하고 H2 판정에는 넣지 않는다.
- **M3**: p마다 seed 3개를 합친다. n_π 주 구간은 [1, 1.2)이고 [1, 2)도 보고한다. 주 칸은 p = 0.03, bootstrap은 장면 1,024개를 재표집한다.
- **H3 주 칸 = H1과 같은 칸**(M1: val·H5·r·(a) 앙상블, M3: p = 0.03, M2: v1.1 칸)
  - 상상 몫 = (P_상상(near) − P_실제(near)) / P_상상(near)
  - **기록**: M1의 이 칸 값은 E1에서 이미 나왔다(0.112 → 0.147, 상상 몫 약 24%). 그래도 가설 간 일관성을 위해 이 칸을 주 칸으로 둔다.
  - DP 집합(a_std, H5)과 다른 판정기·칸은 보조로 모두 보고한다.
- **판정기 (d) 절차**
  - 모델: Qwen2.5-VL-7B-Instruct bf16, SDPA. GPU 공유 때문에 일부 가중치를 CPU에 둔다. 8-bit로 바꾸면 편차로 적는다.
  - 점수: P(Yes | {Yes, No})
  - 입력: 목표 프레임 + 최종 프레임. 실제와 상상 모두 VQ-VAE로 decode한 224 px다.
  - 프롬프트: 고정 3종(dset·r, dset·r_obj, DP 표준)
  - 규칙 집합: dset은 E1 판별기 집합의 held-out에서 AUROC를 재고, 학습 부분으로 문턱을 정한다. DP는 a_std 프레임의 held-out과 학습 부분이다.
  - 기준 AUROC ≥ 0.80을 세 집합에 따로 적용한다. 평가 범위는 E1 val H5(r, r_obj)와 DP H5에서 시작한다.

### 12.3 실패 거리 e, τ, 구간
- **e = ‖(x, y)_최종 − (x, y)_목표‖₂**(상태 단위). **τ = 0.5**: 환경 평가기 `eval_state`의 성공 문턱(DINO-WM의 PointMaze 성공 정의)과 같다. **r = e / 0.5**. 성공 r < 1 ⇔ `eval_state`의 success다(r과 성공 판정이 일치).
- 구간은 2절 그대로다(성공 r < 1, near 1 ≤ r < 2, mid 2 ≤ r < 3, far r ≥ 3). 정의는 하나다(PushT의 r_obj에 해당하는 보조 정의가 없다). 속도 차 ‖Δ(vx, vy)‖는 서술용으로 기록만 한다.
- τ의 화면 크기: 0.5 단위 ≈ 인코더 입력 196 px에서 약 1.4 패치(추정; 스모크에서 실측해 보고에 적는다). PushT의 20 px(≈ 0.55 패치)보다 크다.

### 12.4 episode·목표·상상 (E1 M1 프로토콜 그대로)
- episode = (궤적, offset) 균등 표집, 행동열 T = 5H step(데이터 행동을 로더 평균·표준편차로 역정규화한 원 단위). 시작 관측 = 시뮬레이터가 그린 1프레임(224 px) + proprio(상태 4차원). **목표 = 전문가(데이터) 행동열의 시뮬레이터 결과 상태·프레임**(r = 0; DINO-WM `goal_source=dset` 규약, E1 M1과 같음). 공식 PointMaze 계획 평가는 `random_state` 목표를 쓰지만 B는 계획을 하지 않으므로 목표는 평가 쌍 정의에만 쓰인다(기록).
- 상상: open-loop DINO-WM rollout(1프레임 시작 관측, 행동 정규화 후 5 step씩 묶음, H 단계) → 최종 latent. 실제: 시뮬레이터 최종 프레임(224 px, OSMesa 렌더) → DINOv2 인코딩. 수치 설정은 E1과 같다(SDPA attention, TF32).
- **horizon H ∈ {3, 5, 7, 10}, 주 칸 H = 5**(DINO-WM goal_H = 5). 궤적 길이 100이라 모두 가능하다.

### 12.5 반사실 severity grid (E1 M1과 같은 이분 탐색)
- 반사실 = 전문가 행동열 + s × 패턴. 패턴은 offset(무작위 단위벡터, 구간 내내 일정)과 iid(step마다 N(0, I))를 반씩. s의 단위는 힘(행동) 단위이고, env가 [−1, 1]로 clip한다.
- 표적 r*: 칸마다 3,600개 = [0.8, 3] 층화 균등 3,000 + [0.2, 0.8) 300 + [3, 6] 300. 표적마다 s를 이분 탐색 14회로 정한다. 도달하지 못한 표적은 새 episode로 넘긴다(최대 30회). episode마다 표적 6개와 전문가 행동열(r = 0) 하나.
- 상한 S_MAX(H, 패턴): 보정 집합 C(300 episode)에서 격자 S_GRID = {0, 0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0, 1.5, 2.0, 3.0}로 r의 중앙값을 재고, 중앙값이 6.5에 닿는 가장 작은 격자값(없으면 3.0). 이분 탐색 점검(400 episode: 도달률, |r − r*|)을 함께 한다. 평가 집합 상상 전에 고정.
- 목표: 칸마다 near-miss 1,000개 이상, 궤적 3,000개 이상(6.0절). 벽 때문에 도달 불가가 많으면 도달률을 보고한다.

### 12.6 분할과 칸
- 로더 train 1,800개를 seed 20261101 순열로 **J 800 / C 400 / T 600**(서로 겹치지 않음)으로 나눈다. J는 판별기 학습, C는 보정(S_MAX와 교란 크기), T는 보조 평가(trainsplit). **주 평가는 valid 200개**다. 판별기 학습·보정·평가의 시작 상태는 궤적이 달라 겹치지 않는다.
- 칸 = (집합, H): val × {3, 5, 7, 10}(주) + trainsplit × {3, 5, 7, 10}(보조) = 8칸. **판정 칸: val, H = 5, r, 판정기 (a) 앙상블.**

### 12.7 판정기 (평가 집합을 상상하기 전에 고정)
- **(a)**: E1과 같은 PairJudge([z, z_g, z − z_g] 토큰 → 2층 d = 128 → CLS; C = 384, P = 196), 라벨 r < 1, **K = 5 seed(0~4) 앙상블**(확률 평균 ≥ 0.5). 학습 집합(J): H마다 500 episode × (전문가 + 교란 7개) = 16,000 행동열. 교란 혼합은 E1과 같다(iid 0.35 / offset 0.35 / scale 0.15 / gross 0.15, 크기 = C에서 정한 50% 성공 크기 × log-U[0.3, 3]). 크기 보정 격자(힘 단위): iid σ {0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0, 1.5}, offset β_max {0.01, 0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0}, scale k_max {0.05, 0.1, 0.15, 0.2, 0.25, 0.3, 0.4, 0.5, 0.7, 1.0}(E1과 같음), gross σ_big {0.3, 0.5, 0.7, 1.0, 1.5, 2.0}(σ_small 0.02; P(r ≥ 3) ≥ 0.9인 최소값). episode의 20%를 held-out으로 뺀다(RandomState(0)).
  - **사용 조건: 앙상블의 실제 프레임 held-out 정확도 ≥ 0.95.** 미달이면 E7을 멈추고 보고한다(기준을 낮추지 않는다).
- **상한(probe) 판별기 ai**: 같은 구조를 상상 최종 특징(H 넷 합침)으로 학습, K = 5. H4b용(규칙 대상 아님).
- **(b)**: d_vis 문턱 τ_b = 판별기 학습 부분(실제 프레임)에서 균형 정확도를 최대로 하는 값. PointMaze에는 사전 고정값이 없어 여기서 정하고 평가 전에 고정한다. 보조로만 보고하고 판정에 쓰지 않는다.
- 지각 바닥(실제 프레임의 near 오판)을 먼저 보고한다.

### 12.8 수량, 판정, 통계
- 분석은 `e1_m1_analyze.py`를 과제 전환으로 그대로 쓴다: 구간 확률, log r 로지스틱(전체 → r50·r10, 실패만 → 기울기), 시작 상태 무작위 절편 GLMM, AUROC(실제 / 상상 / probe), **출처 궤적 cluster bootstrap 1,000회**(seed 20261101), horizon 기울기(H마다 같은 재표집).
- **H1b(E7)** — 판정 칸(val, H5, r, (a))에서 세 조항 모두 성립할 때 성립: ① ΔAUROC(성공 대 near) = AUROC_실제 − AUROC_상상 ≥ 0.05, ② ΔAUROC(성공 대 far) ≤ 0.02, ③ [AUROC_상상 − AUROC_실제](성공 대 near)를 H ∈ {3, 5, 7, 10}에 회귀한 기울기의 bootstrap 95% 구간 상한 < 0.
- **H4b(E7)** — 같은 칸에서 (a)의 실제 AUROC(성공 대 near) ≥ 0.95이고, 상상 특징 probe(ai)의 AUROC와의 차 ≥ 0.05(점추정). v3.1 §9 E4b 정의와 같다.
- **서술(판정 없음)**: 지각 바닥, P(상상 성공 | near) [CI], P(상상 성공 | far), near/far, 실패(r ≥ 1)만의 log r 기울기, **양방향 이동**(P(상상 성공 | 성공) − 실제, P(상상 성공 | near) − 실제), r50·Δr10, (b), trainsplit 반복, 앙상블 구성원 SD, 표적 도달률. H1a형 구간 기준(near ≥ 0.3 등)은 참고로만 적는다(E7은 H1a 판정 대상이 아니다).
- **규약 점검(판별기 학습 전, 서술)**: val H5 전문가 episode 200개에서 d_vis(상상 최종, 실제 최종) / d_vis(실제 시작, 실제 최종)의 중앙값을 보고한다. 중앙값 ≥ 1(상상이 "가만히 있기"보다 나쁨)이면 월드모델과 시뮬레이터의 행동 규약이 어긋난 것이므로 멈추고 보고한다(Wall에서 본 종류의 불일치를 막는 점검).
- seed: 분할 20261101; episode seed는 E1 상수 + 700,000(보정 sweep 705000+H, 점검 705100+H·705200+H, 크기 705300+H, worker 707000/707500/707900 + 100H + i; 판별기 집합 episode 708000+H, 혼합 708100+H); 평가 칸 cell_seed = crc32('pm_<집합>_<H>_r') mod 100000(batch seed = cell_seed × 1000 + batch, worker seed = (cell_seed × 100003 + batch × 1000 + i) mod (2³² − 1)); 판별기 seed 0~4; bootstrap 20261101.
