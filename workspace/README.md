# workspace/

A snapshot (2026-10-30) of files from the parent research folder that documents in this repository link to. Paths below `workspace/` mirror the original layout: a link such as `../archive/selection_process/FINAL_IDEAS.md` in a frozen design document corresponds to `workspace/archive/selection_process/FINAL_IDEAS.md` here.

| Path | Contents |
|---|---|
| `MAIN_RULES.md` | Working rules for the main runs of papers A and B (Korean) |
| `MAIN_STATUS.md` | Status board and job table of the main runs (Korean) |
| `JKAIA_POSTER_REVIEW_2026-10-25.md` | Independent review of the A and B JKAIA posters (Korean) |
| `literature/NOVELTY_R2.md` | Novelty search for the round-2 ideas |
| `archive/selection_process/` | Idea-selection documents cited by the designs and pilot plans |
| `runpod_infra/` | RunPod scripts used by the pilots (pod prefix `pai`) |
| `runpod_main/` | RunPod scripts used by the M2 main runs (pod prefix `pmx`) |

Not copied: pod ledgers, per-pod files, watchdog logs and the hourly check log. `budget.py` reads the RunPod API key from the runpodctl config at run time.
